## 〇、愿景拆解：什么叫"对世界充满帮助"

不是算命工具，是**文化基础设施**。四层含义：

| 层 | 含义 | 检验标准 |
|---|---|---|
| **算得准** | 算法经得起外部对拍、用户可以验证 | 对照寿星历/iztro/Swiss Ephemeris，差异有归因 |
| **看得懂** | 排盘结果有解释、有出处、不故弄玄虚 | 每项输出都有「这是什么」+「哪本书说的」 |
| **查得到** | 搜索引擎能找到、术语辞典能定位 | 百度搜"八字排盘 节气"首页可见 |
| **教得会** | 新用户 3 分钟内知道自己该做什么 | 入门引导 → 算第一个盘 → 看懂至少一项结果 |

### 🧮 阶段 B：使用引擎（核心体验）

**当前**：排盘完看到结果，但解释层很薄——一堆术语堆在 Tabs 里，没有「这对你意味着什么」。

**改造后**：每个引擎结果页新增**三区解释系统**——

```
排盘结果
├── 📊 数据区（已有）      ← 天干地支、十神、大运等原始数据
├── 📖 释义区（新增）      ← 对每项数据的白话解释 + 典籍出处
└── 🧠 参详区（已有 AI）   ← AI 解读，明确标注数据来源
```

**八字页示例**：
- 日柱「丙午」→ 📖 释义：「丙为太阳之火，午为离卦正位。丙午日生人，热情外显，如正午烈日——但《滴天髓》云：丙火猛烈，欺霜侮雪，需水既济方成格局。」
- 十神「正官」→ 📖 释义：「正官代表规则、纪律、社会责任。《子平真诠》：正官为用，品性端正。」

**涉及文件**：
| 文件 | 改动 |
|---|---|
| `contracts/bazi-core/glossary.ts` | **新建**：天干/地支/十神/神煞的白话解释字典 |
| `src/components/bazi-v2/ChartDetails.tsx` | 已有 Tabs，新增「释义」Tab |

### 📱 阶段 D：移动端像 App（PWA）

**当前**：有 favicon 和 Apple touch icon，但无 manifest、无 service worker、Google 字体外链阻塞。

**改造后**：

| 改动 | 文件 | 效果 |
|---|---|---|
| 添加 `manifest.json` | `public/manifest.json` | 可安装到主屏幕 |
| 添加 service worker | `public/sw.js` + `vite-plugin-pwa` | 离线缓存 + 二次秒开 |
| 自托管字体 | `public/fonts/` + CSS 改 `@font-face` | 消除 Google CDN 阻塞（国内尤其重要） |
| 添加 `apple-mobile-web-app` meta | `index.html` | iOS Safari 全屏模式 |

### 🔍 阶段 E：让搜索引擎找到（SEO）

**当前**：一篇 `<title>` 打天下，所有页面共享同一个标题。SPA 无 SSR。

**改造后（分两步）**：

**第一步（本周，不改架构）**：
| 改动 | 文件 |
|---|---|
| per-page `<title>` + `<meta>` | `src/App.tsx` 引入 `react-helmet-async`；每个页面设独立标题 |
| `sitemap.xml` | `public/sitemap.xml`（列出所有 15+ 页面） |
| `robots.txt` | `public/robots.txt` |
| Schema.org 结构化数据 | 首页 `WebApplication` + 各引擎页 `SoftwareApplication` |
| OG 封面图 | 为 9 引擎各生成一张 OG 图 |

**第二步（下个迭代，改架构）**：
- 评估 Vike（vite-plugin-ssr）或 Next.js 迁移
- 首页 + 八字/紫微/六爻 这 4 个流量最大的页面先做 SSR
- 迁移成本：~3 天（Vike 方案，改动集中在 `pages/` 和 `vite.config.ts`）
