# 紫府 · 使命宣言（The Zifu Mission）

> 2026-08-17 定稿。这是产品所有决策的最高准则——功能、文案、定价、AI 行为
> 都必须服从于此。每轮迭代对照自查。

## 锚点

**「以古人之智，照今日之心。」**

让流传千年的智慧，成为现代人关照自己的方式。

## 我们相信

1. 玄学的本质是古人创造的自我认知与决策辅助框架——它曾经是那个没有心理
   咨询时代的"倾听者"。
2. 现代人比古人更焦虑、更孤独，但市面上多数玄学产品在害人：制造恐惧、
   收割焦虑、承诺转运。**这是对传统的亵渎。**
3. 历法是科学（我们做到科学级精确）；解读是文化（我们说清楚是文化）；
   引导永远指向建设性行动（睡好觉、好好沟通、想清楚再决定）。
4. 做这件事的意义不是赚钱，是帮助人。商业是让关怀可持续的方式，不是
   让恐惧变本加厉的借口。

## 四类我们想帮助的人

| 人群 | 我们给什么 |
|---|---|
| 迷茫的人 | 借古人的框架停下来想想自己 |
| 孤独的人 | AI 参详与真人师傅的倾听本身就有疗愈价值 |
| 对传统文化好奇的人 | 每次排盘都引经据典，古籍因此活过来 |
| 被算命骗子伤害过的人 | 一个不吓人、可溯源、明说文化属性的平台 |

## 产品铁律（不可妥协）

1. **不制造恐惧**——禁止"灾祸""血光"类营销与断言
2. **不承诺结果**——禁止"必转运""保证准"类话术
3. **历法与解读分界**——历算精确到秒；解读明示"传统视角、文化参考"
4. **引导建设性**——每条解读以自我关照/行动建议收尾，而非宿命结论
5. **免费层永远免费**——基础排盘、每日时令、安寝时令是公益底线
6. **痛苦转介**——用户表露明显痛苦时，引导向亲友或专业心理支持求助

## 商用伦理

- 付费 = 深度服务（AI 参详/人工详批/会员），不是"焦虑税"
- 定价克制（单次 3-9 元，会员 19-29 元）
- 不利用情绪脆弱期营销；退款通道清晰
- 人工师傅先过伦理关（倾听优先于断言）

## 未来延展线

- **关怀线**：命盘解读后引导专业心理资源（合作而非替代）
- **传承线**：藏经阁 → 古籍数字化学习平台（原文/白话/名家导读）
- **守护线**：银发/学生/小生意人定制内容与公益频道
