# 紫府进化自治系统 · 方针与路线（Content-First）

> 2026-08-18 定稿（用户初步认可并深化）。本文件是自治系统的总纲：
> 用户只做决策与改方针；其余由 Hermes 枢纽 + 双工人自主运转。

## 一、核心共识：内容资产是神话

产品的根不是功能数量，是**内容资产的深与精**：
1. **神煞库**——对标问真八字等主流排盘，神煞数量与起例准确度是专业性的脸面
2. **古籍库**——公版典籍蒸馏（原文+白话+可应用规则），引经据典的弹药
3. **对拍体系**——真实命例双源对拍，准确度可证明、可回归

三者构成「专业信任」的闭环：**对拍证明准、古籍证明真、神煞证明全。**

## 二、自治边界

**自主执行（不问）**：功能开发、bug 修复、文案、部署、巡检、古籍补库、神煞扩充、工人管理、对拍扩充。

**决策点（才问用户）**：
- 付费定价与付费墙设计
- 正式域名
- 小程序启动
- 真人师傅接入方案
- 花钱类服务（TTS 等，已给 key 的视为已决策）

**质量铁律**（不合格自动打回，不上报）：
- 测试全绿 + tsc 0 + lint 干净
- git 证据核对（不信自述）
- URL 真实可访问、不编造原文
- 巡检截图复核（移动端三视口）
- 部署后 verify_deploy.py
