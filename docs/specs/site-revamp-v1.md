# 紫府网站改造方案 v1（2026-08-16 定稿）

> 战略共识：移动端（小程序）后置，先完成 Web 站点商用化改造。
> 定位：「古籍数字化研究平台」——古典美感 + 年轻操作。
> 需求视角：四大焦虑场景（睡眠/情感/财富/健康）驱动付费，工具免费引流。

## 一、信息架构改造


## 二、措辞合规（全站统一词汇表）

**禁用词**：预测/算命/改运/化解/补救/消灾/转运/命中注定/必/绝对/准
**统一替用**：参详/解读/参考/趋势/倾向/或可/传统上认为
**页脚免责（全站）**：仅供传统文化研究与娱乐参考，不构成任何
医疗、投资、法律或人生决策建议。

## 四、执行顺序

1. 措辞合规扫描（全站）→ 禁词替换 + 免责声明
2. 首页场景化重排
3. 安寝时令功能（daily-core 扩展——睡眠方向第一枪）
4. 四大场景页搭建（骨架先行，内容渐进）
