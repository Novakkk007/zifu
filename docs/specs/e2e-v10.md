## 3. 明确不验收（本期排除）

- 引擎算法正确性（由 Hermes 外部对拍体系负责，非 E2E 职责）
- 视觉像素级回归（V10 不引入 screenshot diff，避免脆性测试）
- 性能预算硬门禁（先采集数据，V11 再定阈值）

## 4. 反脆性约束（提议）

- 选择器优先级：data-testid > role/label > 文本 > CSS；禁止路径式选择器
- 禁止 sleep 式等待，一律用 expect 轮询
- 每个场景独立可重跑，无顺序依赖

3. 是否需要引入 axe-core 无障碍扫描作为第 8 项？
