## 通用交互规范
- 按钮 5 变体 × 8 态（default/hover/active/focus/disabled/loading/success/error），防重复提交
- 表单：label/错误/提示齐全，focus 金环，移动 ≥44px 触控
- 弹层：focus trap + ESC + 遮罩点击关闭
- Tabs：滑动 + 键盘箭头
- 全部循环动画尊重 prefers-reduced-motion
- 空态/错误态/加载骨架三态齐全
