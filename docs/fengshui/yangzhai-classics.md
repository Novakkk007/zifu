# 阳宅风水典籍蒸馏：《宅经》（旧题《黄帝宅经》）

> 定位：公版古籍的文化整理与安全转译，不是建筑设计规范，也不用于预测个人祸福。
> 使用边界：任何提示都必须让位于现行法律、规划、消防、结构、采光、通风、给排水、无障碍及专业检测结论。

## 1. 典籍概览

| 项目 | 蒸馏结论 |
|---|---|
| 书名 | 传世本通常称《宅经》，旧题《黄帝宅经》，分卷上、卷下。 |
| 成书年代 | 确切年代不明。传世文本提及李淳风、吕才等人的宅经，成书不得早于唐初相关人物；可暂称“唐以后汇编、后世递修的相宅文献”，不写成黄帝时代著作。 |
| 作者可信度 | “黄帝撰”不可信。《四库全书总目提要》明确判断“是书盖依托也”，并认为后来方技者为抬高其说而题作黄帝。 |
| 文献地位 | 四库馆臣称其在术数文献中“犹最为近古者”，并疑《宋史·艺文志》所载《相宅经》一卷即此书；这说明它有文献史价值，不等于其中术数结论经过科学验证。 |
| 内容性质 | 把住宅、方位、阴阳、家庭秩序与营建禁忌合为一套解释体系。卷上、卷下存在版本异文和转录讹误，适合研究观念史，不宜直接当作施工手册。 |
| 经验可信度 | 关于空间尺度、门户比例、围护完整、清洁维护的观察，可转译为居住体验检查项；方位致祸、命座、神煞、特定日期修造等说法缺少可重复验证，可信度低，不进入确定性判断。 |

## 2. 核心框架蒸馏

### 2.1 宅之“五虚五实”

《宅经》所谓“虚、实”，不是现代建筑学的实体率计算，而是用十组情形描述住宅规模、使用强度和维护状态。

| 古籍条目 | 可理解的观察对象 | 本项目处理 |
|---|---|---|
| 宅大人少 / 宅小人多 | 面积与常住人数是否失衡 | 仅提示空置率、维护负担、拥挤和收纳，不推断贫富。 |
| 宅门大内小 / 宅大门小 | 入口与内部体量比例 | 提示入口尺度、保温、私密和通行体验；实际尺寸按规范及使用需求确定。 |
| 墙院不完 / 墙院完全 | 围护是否破损 | 转为围护、门窗、渗漏和安防巡检。 |
| 井灶不处 | 取水与炊事设施的位置 | 转为饮用水、污水、燃气、排烟和防火检查，不沿用古代方位禁忌。 |
| 地多屋少庭院广 | 土地与建筑使用率 | 仅提示闲置区域的照明、排水、维护和可达性。 |
| 宅小六畜多 | 前现代家畜与居住混用 | 现代住宅不直接应用；如有宠物，只提示卫生、通风和动物福利。 |
| 水沟东南流 | 特定排水方向 | 排除。现代排水由地形、管网、坡度、防倒灌和法规决定，东南方向不具有普遍效力。 |

**蒸馏结论：**可保留的是“尺度合用、入口协调、围护完整、设施适位、持续维护”五类检查，不保留“因此富贵/贫耗”的因果断言。

### 2.2 二十四路方位体系

《宅经》以院落为中心，把周边分作二十四路。后世常见的“二十四山”排列如下：

| 八方 | 三个方位标签 |
|---|---|
| 北 | 壬、子、癸 |
| 东北 | 丑、艮、寅 |
| 东 | 甲、卯、乙 |
| 东南 | 辰、巽、巳 |
| 南 | 丙、午、丁 |
| 西南 | 未、坤、申 |
| 西 | 庚、酉、辛 |
| 西北 | 戌、乾、亥 |

这里实际使用的是八个天干（甲、乙、丙、丁、庚、辛、壬、癸）、十二地支与乾坤艮巽四隅；戊、己居中而不列周圈。传世原文却写“十干十二支乾艮坤巽，共为二十四路”，算数上为二十六，属于必须披露的文本/体系矛盾。

《宅经》的高层逻辑是：

1. 先以住宅中心和实测方向建立二十四路标签；方向仅是空间索引。
2. 再把乾、坎、艮、震一组与巽、离、坤、兑一组作阴阳分类，强调相互调剂而不是单边极端。
3. 继而把不同部位附会为“福德”“刑祸”“命座”等，推断休咎。

前两步可用于理解古代空间分类史；第三步缺乏可验证因果，只能展示为“古籍如此分类”，不得输出“某方必吉/必凶”。现代朝向评价应改用日照时数、遮挡、风环境、噪声、热负荷和当地气候数据。

### 2.3 门、主、灶关系

“门—主—灶”作为三项组合的固定术语，主要见于后起的明清阳宅体系；传世《宅经》虽分别谈门户、宅主、井灶，却没有一套可直接抽取的“门主灶八宅组合表”。因此不得把后世歌诀倒填成《黄帝宅经》规则。

可安全转译的三项关系是：

- **门**：进入、疏散、换气、噪声与视线的接口。
- **主**：主要起居或睡眠空间，关注采光、安静、私密与可达性。
- **灶**：烹饪和热源区域，关注燃气/电气安全、排烟、防火、清洁及操作动线。
- **关系检查**：入口是否直冲私密空间、主要通道是否穿越灶台操作区、门窗穿堂风是否干扰火焰或排烟、厨房油烟是否进入主要起居空间。

这些是现代功能性复核，不是古籍吉凶复刻，也不以宅向推出事件。

### 2.4 宅命相配

“宅命相配”通常指后世八宅法把住宅卦类与个人年命卦配对。它与《宅经》的二十四路阴阳宅体系不能无缝等同；《宅经》一方面有“命座”叙述，另一方面又批评当时流行的“五姓八宅、黄道白方”。因此：

- 不建立“出生年/性别 → 命卦 → 吉凶方”的生产规则；
- 不因家庭成员之间所谓命卦冲突而建议换房、换卧室或改门；
- 若用户主动询问，只说明其属于传统分类，不作健康、婚姻、财富和安全预测；
- 真正的人宅匹配改看身高与尺度、年龄、行动能力、作息、感官需求、照护关系及无障碍条件。

### 2.5 吉凶方位判定逻辑

古籍判定链可概括为：

`定中心与二十四路 → 分阴宅/阳宅及阴阳位 → 叠加福德、刑祸、命座、时日 → 赋予休咎`

本项目只允许保留前两步作为文化标签，并把后两步降级为来源说明。若要生成现代居住提示，应改为：

`确认户型与真北 → 获取气候和现场数据 → 检查采光/通风/消防/结构/卫生/动线 → 给出可验证提示`

方向不清、户型缺失或现场条件未知时，不作方位判断。

## 3. 可应用规则（条件 + 提示）

以下规则只产出“检查提示”，不产出吉凶结论。

| 规则 ID | 条件 | 提示 |
|---|---|---|
| YZ-01 空间使用 | `住宅面积明显大于实际需求 + 常住人数少/大量长期空置` | → “可检查空置房间的渗漏、霉变、通风、能耗与维护成本；这对应古籍‘宅大人少’的空间观察，不代表贫富结果。” |
| YZ-02 入口比例 | `入口尺度/开口明显大 + 内部空间小或入口直曝主要起居区` | → “可复核保温、噪声、私密、门扇碰撞与疏散净宽；不要仅凭‘门大’判断好坏。” |
| YZ-03 围护完整 | `院墙/门窗/屋面/外墙出现破损、松动或渗漏` | → “优先安排结构与围护巡检，处理坠落、进水、虫害和安防风险；这是维护建议，不是灾祸预测。” |
| YZ-04 井灶适位 | `饮用水/排污设施与厨房相邻不当，或燃气、排烟、防火条件不明` | → “请按当地给排水、燃气和消防规范复核，必要时请持证专业人员检测；古代方位法不能替代检测。” |
| YZ-05 门主关系 | `入户门视线直达主要卧室/起居私密区` | → “可用玄关、错位收纳或可控遮挡改善私密与声光干扰，同时保持疏散通道畅通。” |
| YZ-06 门灶关系 | `主要入户/通行路线穿越烹饪操作区，或强穿堂风掠过灶具` | → “复核碰撞、烫伤、火焰稳定和排烟风险；调整方案必须先满足消防、燃气与通行规范。” |
| YZ-07 宅向复核 | `用户提供宅向 + 门位 + 主位，但没有真北、测量误差、户型或现场数据` | → “信息不足，暂不判方位；请补充可靠测量和空间资料。即使资料齐全，也只给文化标签与环境检查项。” |
| YZ-08 宅命请求 | `输入出生年/性别，要求匹配住宅或断吉凶` | → “宅命相配属于传统术数分类，不能据此预测事件；可改按居住者的行动、作息、采光、安静和无障碍需求评估。” |
| YZ-09 多体系冲突 | `《宅经》二十四路 + 后世八宅/门主灶表得出冲突标签` | → “标注来源时代和体系不同，不强行合并、不择凶词放大；转回可测的采光、风、噪声、消防和卫生指标。” |

## 4. 公版原文引录与白话对照

以下每条引文均不超过 80 字，均出自公版《宅经》或《四库全书》提要；繁体保留原貌，标点为便于阅读所加。白话是本项目自译。

1. **原文：**“夫宅者，乃是陰陽之樞紐，人倫之軌模。”
   **出处：**《宅经》卷上。
   **白话：**住宅被视为阴阳关系的枢纽，也是家庭生活秩序的空间模型。

2. **原文：**“故宅者人之本。人以宅為家居。”
   **出处：**《宅经》卷上。
   **白话：**书中把住宅看作人的生活根基，因为人以住宅安顿家庭。

3. **原文：**“今采諸秘驗，分為二十四路，八分九宮，配女男之位。”
   **出处：**《宅经》卷上。
   **白话：**作者汇集旧说，把住宅周边分成二十四路，并结合八方九宫与男女位置解释。

4. **原文：**“二十四路者，隨宅大小，中院分四面作二十四路。”
   **出处：**《宅经》卷上。
   **白话：**所谓二十四路，是以院落为中心，沿四周划分二十四个方位段。

5. **原文：**“陽不獨王，以陰為得；陰不獨王，以陽為得。”
   **出处：**《宅经》卷上。
   **白话：**书中主张阴阳不应各自走向极端，而以彼此调剂为理想。

6. **原文：**“宅有五虛，令人貧耗；五實，令人富貴。”
   **出处：**《宅经》卷上。
   **白话：**古人把五类住宅状态称为“五虚”“五实”，并附会为贫耗或富贵；后半因果不采信。

7. **原文：**“宅大人少，一虛；宅門大內小，二虛；牆院不完，三虛。”
   **出处：**《宅经》卷上。
   **白话：**房屋过大而人少、入口与内部比例失调、围墙院落破损，被列作前三种“虚”。

8. **原文：**“宅小人多，一實；宅大門小，二實；牆院完全，三實。”
   **出处：**《宅经》卷上。
   **白话：**房屋较小而人口多、房屋大而门较小、围护完整，被列作前三种“实”；现代不把拥挤视为优点。

9. **原文：**“宅以形勢為身體，以泉水為血脈，以土地為皮肉。”
   **出处：**《宅经》卷上。
   **白话：**书中用身体作比喻，把整体形势、水源和土地看成住宅系统的组成部分。

10. **原文：**“以草木為毛髮，以舍屋為衣服，以門戶為冠帶。”
    **出处：**《宅经》卷上。
    **白话：**比喻继续把植被、房屋和门户看作相互配合的外部层次。

11. **原文：**“是書蓋依託也。”
    **出处：**《四库全书总目提要·宅经》。
    **白话：**四库馆臣判断，本书托名古人，并非黄帝所作。

12. **原文：**“在術數之中猶最為近古者矣。”
    **出处：**《四库全书总目提要·宅经》。
    **白话：**四库馆臣认为它在术数文献中相对接近古制；这是文献年代评价，不是科学有效性证明。

## 5. 不可应用部分

以下内容仅可在历史说明中出现，不得生成面向用户的决策建议：

1. **确定性祸福断言**：把某个方位、门位或修造动作直接说成致贫、致病、绝嗣、死亡、升官或暴富。
2. **神煞与禳镇**：天德、月德、太岁、豹尾、黄幡、黑方、镇符、禳解等缺乏可靠证据，不建议摆物、拆建或付费化解。
3. **命座与身份绑定**：按父母、长幼、男女、姓氏、出生年给人固定方位并预测遭遇，既不可验证，也可能制造性别和家庭角色偏见。
4. **古代工期与日期禁忌**：按月份、干支决定开工或避工，不能替代工程勘察、许可、天气、供应链和施工安全计划。
5. **六畜、马厩、仓廪的旧式配置**：不直接套用于公寓、办公楼和现代城市住宅；相关需求按卫生、防疫、消防和用途管制处理。
6. **固定排水方向**：“水沟东南流”等说法排除。排水必须依据实测标高、暴雨强度、管网接口、防洪防涝和防倒灌要求。
7. **以方位替代工程诊断**：裂缝、沉降、潮湿、燃气异味、电气过热等问题必须由相应专业人员检查，禁止解释为“气场”后拖延处置。
8. **跨体系拼盘**：不得把《宅经》、后世八宅法、门主灶、飞星或现代作者观点拼成一个貌似古老且唯一的算法。
