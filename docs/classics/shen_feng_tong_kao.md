# 《神峰通考》蒸馏文档

## 概览
- 成书年代：明代（约公元14-17世纪）
- 作者：张楠（号神峰子）
- 地位：明代命理学重要著作，开创了"病药说"理论，强调命局中的"病"与"药"关系
- 特点：系统阐述了命局中各种"病"的类型及相应的"药"，强调对症下药的命理分析方法

## 核心方法蒸馏

### 病药理论判定逻辑
- 病的定义：命局中过旺、过弱、受克、受制、混杂等失衡状态
- 药的定义：能够治疗"病"的用神或组合
- 病药关系：有病方为贵，无伤不是奇；病重药轻则不治，病轻药重则反伤

### 八种病状判定逻辑
- 太旺：日主或某五行过旺，需克泄耗
- 太弱：日主或某五行过弱，需生扶
- 受克：某五行被克制过重，需化解或制克者
- 受制：某五行被制约过重，需解除制约
- 混杂：用神忌神混杂，需清纯
- 相战：五行相战（如金木相战），需通关
- 空亡：地支空亡，需填实或引动
- 伏吟：干支伏吟，需解伏

### 病药对应逻辑
- 太旺之病：以克泄耗为药
- 太弱之病：以生扶为药
- 受克之病：以制克者或化解者为药
- 受制之病：以解除制约者为药
- 混杂之病：以清纯者为药
- 相战之病：以通关者为药
- 空亡之病：以填实或引动者为药
- 伏吟之病：以解伏者为药

## 可应用规则

1. **病药识别规则**：
   - 条件：命局存在明显失衡状态
   - 提示格式："命局[病状]，宜[药]治之，忌[加重病状]"

2. **太旺病规则**：
   - 条件：日主或某五行得令得地得势
   - 提示 format："[五行]太旺，宜[克/泄/耗]为药，忌[生扶]"

3. **太弱病规则**：
   - 条件：日主或某五行失令失地失势
   - 提示格式："[五行]太弱，宜[生/扶]为药，忌[克/泄/耗]"

4. **受克病规则**：
   - 条件：某五行被克制过重
   - 提示格式："[五行]受克，宜[制克者/化解者]为药，忌[克者]"

5. **混杂病规则**：
   - 条件：用神忌神混杂不清
   - 提示格式："[用神/忌神]混杂，宜[清纯者]为药，忌[混杂者]"

6. **相战病规则**：
   - 条件：五行相战（金木、水火等）
   - 提示格式："[五行]相战，宜[通关者]为药，忌[相战者]"

7. **空亡病规则**：
   - 条件：地支空亡影响用神
   - 提示格式："[地支]空亡，宜[填实/引动]为药，忌[空亡]"

8. **病药平衡规则**：
   - 条件：病重药轻或病轻药重
   - 提示格式："病[重/轻]药[轻/重]，宜[调整药力]，忌[过度用药]"

## 公版原文引录

1. "有病方为贵，无伤不是奇。"（有病才有贵气，没有损伤不算奇特）
2. "病重药轻则不治，病轻药重则反伤。"（病重药轻治不好，病轻药重反而伤害）
3. "药不对症，不如不服；症不对药，徒劳无功。"（药不对症不如不吃，症不对药白费功夫）
4. "病去如抽丝，药到病自除。"（病去如抽丝般缓慢，药到自然病除）
5. "医不三世，不服其药；命不精微，不谈其理。"（医生不到三代不服用他的药；命理不精微不谈论其中的道理）
