# 《星命溯源》蒸馏文档

## 概览

- 主题：七政四余传统中的历算精度、星曜状态、宫度及三方对照。
- 选书说明：本批采用有完整公版正文可实证的《星命溯源》，不沿用半成品中无法核验的《果老星宗》伪引。
- 使用边界：星命术语只作历史文化与规则结构展示，不用于现实吉凶、健康、寿命或身份预测。

## 版本与成书考证

今据维基文库《星命溯源（四库全书本）》全览；四库提要称全书五卷、不著编辑者名氏，并说明卷一杂录唐张果之说，故不把全书直接署为张果亲著。

## 核心方法蒸馏

### 历算数据先于解释

- 原文首先要求星历端正，并强调太阴晨昏起度的误差会放大。
- 出生时间、地点、历法或星历数据不可靠时，应停止细断并展示不确定性。

### 多维状态而非吉凶标签

- 文本先看星曜的明暗、升沉、顺逆、衰旺、掩蚀、冲制与入垣等状态。
- 再看朝、拱、夹、辅、分、会、引、从等关系；不能把某颗星固定贴成“吉星”或“凶星”。

### 三方对照与变通

- 宫度、命度及三方关系应联合观察。
- 古籍自身明言“局面在乎变通”，因此单星、单宫或单一组合不足以形成稳定提示。

## 公版原文摘录

以下按所据页面原字转录，并补现代标点以便阅读。

1. **原文**：“一排命先求星厯端正，太隂晨昏起度不差；若差之毫釐，繆以千里。”
   **白话**：排定星盘先要保证星历和月亮度数准确，小误差可能令后续判断显著偏离。
2. **原文**：“取三方對照生尅帶貴帶殺若何，夜生人重身度主要𦂳。”
   **白话**：原法要求把三方照应、生克与身度等因素合看，而不是只看一个宫位。
3. **原文**：“一觀命局面在乎變通。”
   **白话**：盘面解释重在结合上下文变通，不能机械套用单条口诀。
4. **原文**：“先看明暗升沉順逆衰旺掩蝕衝制失次入垣，次看朝拱夾輔分㑹引從漏截守岐方，以格局考評貴賤。”
   **白话**：先看星曜自身状态，再看星曜之间的组合关系；末句的“贵贱”属于古代等级语汇，不用于现代输出。
5. **原文**：“如尅我之讐星既強盛而我衰弱，全賴母子二星以援，在本宫及對闗加合以生以救。”
   **白话**：当某种制约关系偏强时，原法还会检查其他星曜能否通过宫位和会照形成缓冲。

## 可应用规则

1. **数据精度门槛**
   条件：出生时刻、地点、时区、历法换算或星历精度任一项不可靠。
   → 提示：“《星命溯源》把星历精度置于解释之前；当前数据不足，只展示误差范围，不作细分文化判断。”
2. **星曜状态清单**
   条件：需要解释某一七政或四余。
   → 提示：“先列明暗、升沉、顺逆、衰旺、掩蚀、冲制、入垣等状态，再讨论关系；不固定贴吉凶标签。”
3. **三方对照提示**
   条件：某星落入重点宫度。
   → 提示：“请同时查看三方及对照关系、生克和会合；单星落宫不足以形成结论。”
4. **变通复核提示**
   条件：不同规则对同一组合给出相反倾向。
   → 提示：“依古籍‘局面在乎变通’的原则，展示支持与抵消证据，并保留不确定性。”
5. **历史语汇降级**
   条件：原文出现贵贱、禄位、寿夭、疾病等断语。
   → 提示：“仅标注为历史文本中的判断范畴，不转换成现代人的身份、健康或命运预测。”

## 不可应用清单

- 不使用星曜组合预测死亡、疾病、灾害、刑罚、贫富、官职或考试结果。
- 不依据出生盘评价人的道德、智力、外貌、性别角色或社会等级。
- 不把四余或传统煞名解释为天文学上的物理因果。
- 不在历算数据缺失时用模糊时辰强行补盘。
- 不把《星命溯源》各卷材料统称为张果亲著，也不沿用未命中正文的《果老星宗》链接与引句。
