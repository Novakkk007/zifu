# 《子平真诠》蒸馏文档

## 概览

- 主题：以月令取用为起点，观察用神、相神以及全局配合。
- 使用边界：以下内容只整理传统文本的分析顺序，用作条件型文化提示，不把格名换算为现实成败或人生等级。

## 版本与成书考证

今据中国哲学书电子化计划公开的《子平真詮評注》全文页；该页书目署清代沈孝瞻，本文只摘录正文中可直接核对的句子，不把评注中的扩写反署给原作者。

## 核心方法蒸馏

### 月令取用

- 先确定月支与日干的生克关系，再讨论传统格名。
- “专求月令”是观察起点，不等于只看月令；仍需回到全局配合。

### 顺用、逆用与变化

- 原文把财、官、印、食归为“善而顺用”，把煞、伤、劫、刃归为“不善而逆用”。这是古籍内部的技术分类，不是现代道德评价。
- 月令藏干透出、会合或相克时，用神会呈现变化；判断重点是参与因素能否相互配合，而不是机械套一个格名。

### 相神与格局成败

- 相神是令全局结构成立的辅助因素，不固定等同某一个十神。
- “成”与“败”只描述传统模型内部结构是否自洽，不外推为财富、婚姻、健康或身份结论。

## 公版原文摘录

1. **原文**：“八字用神，專求月令，以日乾配月令地支，而生克不同，格局分焉。”
   **白话**：取用先从月支出发，把日干与月支的生克关系作为划分传统格局的入口。
2. **原文**：“用神既有變化，則變化之中，遂分純、雜。”
   **白话**：取用发生变化后，还要分辨各参与因素是彼此协调，还是互相牵制。
3. **原文**：“八字既有用神，必有格局，有格局必有高低……然其理之大綱，亦在有情無情、有力無力之間而已。”
   **白话**：文本评价格局时，主要观察配合是否有情、相关因素是否有力；其中“高低”是古代术语，不作现代身份判断。
4. **原文**：“月令既得用神，則別位亦必有相，若君之有相，輔者是也。”
   **白话**：月令取用之后，还要找出其他位置中能够辅助该结构的因素。
5. **原文**：“凡全局之格，賴此一字而成者，均謂之相也。”
   **白话**：凡是对全局结构成立起关键辅助作用的那个因素，书中称为“相”。

## 可应用规则

1. **月令起点提示**
   条件：排盘数据完整，且月支、日干及藏干关系可确定。
   → 提示：“按《子平真诠》的文化视角，可先由月令观察取用，再结合其余干支复核；不宜只凭月令下结论。”
2. **顺逆用提示**
   条件：月令所取十神可归入财官印食或煞伤劫刃。
   → 提示：“古法会区分顺用与逆用；这里的‘善/不善’是技术标签，请继续检查生、护、制、化关系。”
3. **用神变化提示**
   条件：月令藏干多透，或有会合使原有关系改变。
   → 提示：“取用可能随透干、会合而变化，可比较各因素是相得还是相碍，不机械固定格名。”
4. **相神复核提示**
   条件：已经得到候选用神。
   → 提示：“继续寻找令全局结构成立的辅助因素；相神取决于全局作用，不预设为固定十神。”
5. **格局状态提示**
   条件：候选用神或相神受到合、冲、克、泄。
   → 提示：“可标记传统模型中的结构变化与不确定性；‘成败’只描述模型内部配合，不对应现实吉凶。”

## 不可应用清单

- 不输出“富贵、贫贱、寿夭”等身份或命运定论。
- 不用格局推断职业成就、财富水平、疾病、婚姻质量或道德品格。
- 不把“善用、不善用”解释为人的善恶。
- 不在出生时间、历法换算或藏干数据不确定时强行取格。
- 不把后世评注、网络改写或白话说明伪装成沈孝瞻原文。
