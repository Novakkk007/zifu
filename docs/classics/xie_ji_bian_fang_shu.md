# 《协纪辨方书》蒸馏文档（建除十二神）

## 概览

- 成书年代：清乾隆四年（1739）奉敕撰，历时三年完成；收入《四库全书》子部术数类。
- 编撰：允禄、何国宗、梅瑴成等奉敕编纂（乾隆御定）。
- 地位：清代官方择日/术数总汇，统摄「建除家」「丛辰家」等诸家之说，是传统择日（黄历）体系的集大成官方定本。
- 特点：全书三十六卷（本原、义例、立成、宜忌、用事、公规、年表、月表、日表、利用、附录、辨讹等）。本蒸馏聚焦其中**义例·建除十二神**部分——即黄历每日所标「建、除、满、平、定、执、破、危、成、收、开、闭」十二值位的由来与逐日推法。
- 公版状况：古籍本体已入公版（清代官修、四库本）。本蒸馏只使用公版原文（四库本转录文本），不复制现代整理本/译注内容。

## 核心方法蒸馏

### 建除十二神（建除十二建星）

十二值位按固定次序周而复始：

> 建、除、满、平、定、执、破、危、成、收、开、闭

原书（依《历书》/《淮南子》转录）：「历家以建除满平定执破危成收开闭凡十二日周而复始，观所值以定吉凶，每月交节则叠两值日，其法从月建上起建，与斗杓所指相应，如正月建寅，则寅日起建，顺行十二辰是也。」

### 逐日推法（起建规则）

- 以当月**月建**所在之日为起点，当日记「建」，次日记「除」，依次顺行十二辰，十二日一周而复始。
- 例：正月建寅 → 寅日建、卯日除、辰日满、巳日平、午日定、未日执、申日破、酉日危、戌日成、亥日收、子日开、丑日闭；到下一个寅日复为「建」。
- 每月「交节则叠两值日」：月节交节当日会叠两值日（节前置前月值、节后置新用当建之月值）。
- 原书引《淮南子》对照方位与值位：「正月建寅则寅为建，卯为除，辰为满，巳为平，午为定，未为执，申为破，酉为危，戌为成，亥为收，子为开，丑为闭。」

### 十二值位的吉凶归类（考原所载歌诀）

原书《考原》引历书约定：

| 值位 | 归类 | 备注 |
|---|---|---|
| 除、危、定、执、成、开 | 吉 | 「除危定执黄」 |
| 建、破、平、收、满、闭 | 凶 | 「建满平收黑」 |
| 成、开 | 皆可用 | 「成开皆可用」 |
| 闭、破 | 不相当（最凶） | 「闭破不相当」 |

但原书强调此吉凶不可执一而论：「吉神多则吉，凶神多则凶，又各视其神之宜忌以为趋避，亦未可以执一而论也。」（详见「不可应用」部分）

### 十二值位的义理与所合丛辰（同位异名）

原书「建除同位异名」表（建除十二神在丛辰系统中的别名/所合）：

- **建**：兵福、小时、土府
- **除**：吉期、兵宝
- **满**：福德、天巫、天狗
- **平**：阳月天罡、阴月河魁、死神
- **定**：时阴、官符、死气
- **执**：枝德、小耗
- **破**：大耗
- **危**：（无专门同位异名）
- **成**：天医、天喜
- **收**：阳月河魁、阴月天罡
- **开**：时阳、生气
- **闭**：血支

原书对建除十二字义理循环的阐释（节录）：

> 建者一月之主，故从建起义而参伍于十二辰，古之所谓建除家言也。建次为除，除旧布新。……满则必溢……故继之以平。平则定，建前四位则三合，合亦定也。定则可执矣，故继之以执，执者守其成也。物无成而不毁，故继之以破。救破以危……继危者成，何以成，建三合备也。既成必收，自建至此而十，十者极数也。……开之云者，十即一也。……建固生于开者也，故开为生气也。气始萌芽不闭……故受之以闭终焉。唯其能闭，故复能建，与《易》同也。

### 十二值位逐日宜忌（历书通行说法，仅作文化提示）

- **建日**：万物初始。宜建基、破土、开斧、开光、安座；其余多不宜（历书另载建日不利行师）。又「建为岁君、元神、吉凶众神之主帅」，可坐不可向。
- **除日**：清除、吐故纳新。宜清洁、沐浴、求医、安葬等。
- **满日**：圆满。宜吉庆之事；忌凶事、不吉事。
- **平日**：平顺。喜凶之事均可办（选择宗镜称「平日甚吉」）。
- **定日**：安定、有定。宜安床、祈福、婚娶、商贾、考试；忌搬迁、开张。
- **执日**：固执守成。喜凶事皆有所宜忌（择日上多不取）。
- **破日**：破裂、冲破。「岁破为大耗，大凶」；忌一切喜凶事。
- **危日**：危险、须小心。可办事但要小心，大事小用（选择宗镜称「危为极富星、谷将星、四利龙德，吉」——吉凶源流不一，见不可应用）。
- **成日**：成就、结果。喜凶诸事皆可办，主先难后易。
- **收日**：收回、收敛。宜收敛、索取（账簿入库、埋葬）等；余事不宜。
- **开日**：开通顺利，百事可行。「开为青龙、太阳、生气、华盖，上吉」。
- **闭日**：闭塞不通。宜收敛、埋葬，余事不宜。「闭为病符，凶」。

> 说明：以上宜忌来自历书/通书通行说法及选择宗镜等注家，属传统择日文化表述，仅作**条件型文化提示**，不构成现实决策或吉凶断言（见下「可应用规则」与红线）。

## 可应用规则（→ 条件型文化提示，无吉凶断言）

以下规则只在紫府诸页作「传统择日文化提示」引用，不给出确定性吉凶结论，不参与任何现实决策。

1. **建除逐日推算规则**
   - 条件：输入某农历日及其所在月的月建地支。
   - 推法提示：以该月「月建」日定为「建」，依建→除→满→平→定→执→破→危→成→收→开→闭 顺行十二辰，遇「叠两值日」之交节当日按原书提示标注。
   - 展示格式：列出该日所「值」建除位，及该值位在十二值中的次序。

2. **值位吉凶归类提示（流派标注）**
   - 条件：输出某建除值位的吉凶归类。
   - 提示格式：注明「按《考原》引历书：建满平收黑、除危定执黄、成开皆可用、闭破不相当」，并**同时标注**择日流派观点的差异（如危日在选择宗镜被视为吉、历书多作凶），不得单方定性。

3. **同位异名/所合丛辰提示**
   - 条件：输出建除值位与其丛辰别名。
   - 提示格式：给出原书「同位异名」（如建=兵福/小时/土府，开=时阳/生气），并注明此为「建除家与丛辰家之异名同实」的文化梳理。

4. **输入完整性门槛**
   - 条件：缺少可靠农历月建、交节日或朔望信息。
   - 提示：「建除十二神须先定当月月建与交节；当前历法信息不足，仅介绍建除十二值位概念，不作逐日推演。」

## 不可应用清单

- **不得输出确定性吉凶断言**：原书明言建除吉凶「不可执一而论」，且各家（历书 vs 选择宗镜）对危日等吉凶源流不一；不提供「某日吉/凶可做某事」的现实结论。
- **不替代历法/天文事实**：建除十二神是传统择日体系的文化概念，与天文学事实无关，不得包装为科学结论。
- **不推导命运/生死病灾**：仅作文化现象与术语说明，不据此输出个人命运、健康、事业等断言。
- **叠值日与交节处理**：原书「每月交节则叠两值日」的精确置闰/交节日程涉及完整历算，本蒸馏不作精确到日的推算承诺（工程上需接入可靠历法引擎）。

## 公版原文引录（仅公版四库本原句，均经原文转录核验）

1. 「历家以建除满平定执破危成收开闭凡十二日周而复始，观所值以定吉凶，每月交节则叠两值日，其法从月建上起建，与斗杓所指相应，如正月建寅，则寅日起建，顺行十二辰是也。」
   （白话：择日家把建除满平定执破危成收开闭这十二个值位，十二日周而复始，按当日所值来定吉凶；每月交节时当天会叠加两个值日，方法是从当月月建所在之日起「建」，顺行十二地支。）
   —— 原书义例「建除十二神」转引《历书》（四库本卷四）

2. 「淮南子曰：正月建寅则寅为建，卯为除，辰为满，巳为平，午为定，未为执，申为破，酉为危，戌为成，亥为收，子为开，丑为闭。」
   （白话：正月建寅，则寅日是建，卯日是除，辰日是满，巳日是平，午日是定，未日是执，申日是破，酉日是危，戌日是成，亥日是收，子日是开，丑日是闭。）
   —— 原书义例转引《淮南子·天文训》

3. 「考原曰：按月建十二神，除危害定执成开为吉，建破平收满闭为凶。历书所谓：建满平收黑，除危定执黄，成开皆可用，闭破不相当者也。」
   （白话：按《考原》，建除十二神中除、危、定、执、成、开为吉，建、破、平、收、满、闭为凶。即历书歌诀所说「建满平收黑，除危定执黄，成开皆可用，闭破不相当」。）
   —— 原书义例《考原》引历书

4. 「建者一月之主，故从建起义而参伍于十二辰……唯其能闭，故复能建，与《易》同也。」
   （白话：建是当月之主，因此从「建」起义并贯穿于十二地支……正因为能「闭」，所以又能重新「建」，这与《周易》的道理相通。）
   —— 原书义例「建除十二神」按语（节录）

5. 「大抵凡日吉神多则吉，凶神多则凶，又各视其神之宜忌以为趋避，亦未可以执一而论也。」
   （白话：大致而言，当日吉神多则吉、凶神多则凶，还要看各神本身宜忌来趋避，不能固执一端一概而论。）
   —— 原书义例「建除十二神」按语
