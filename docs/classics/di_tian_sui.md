# 《滴天髓》蒸馏文档

## 概览

- 主题：以阴阳五行的时、地、势及其流转，讨论旺衰、流通与寒暖燥湿。
- 使用边界：只保留可转化为观察步骤的内容，所有提示均为传统文化参详，不作吉凶保证。

## 版本与成书考证

《滴天髓》传统上相传为明代刘基所作，作者归属历来有争议；本文据维基文库《滴天髓》公开全文整理，并把作者表述保留为“传”。

## 核心方法蒸馏

### 旺衰不是单一计数

- 原文从四时之气切入，强调五行是否“得时”；实际提示还应同时列出得地、得助、受制等证据。
- 不用“同类多就是旺、异类多就是衰”的简单数量替代关系分析。

### 流通先找源头与落点

- 观察一组生克关系从何处发动、向何处传递、在哪里受阻或停住。
- 所谓“流通”只描述传统模型中的作用链，不映射为现实事件必然发生。

### 寒暖燥湿作为独立维度

- 冬夏寒暖、土气燥湿可单独列为参详维度。
- 调候不能覆盖旺衰与结构分析，也不能把某一五行直接等同药物、颜色、职业或现实补救措施。

## 公版原文摘录

1. **原文**：“欲識三元萬物宗，先觀帝載與神功。”
   **白话**：要理解文本中的整体框架，先看天时运行及其作用。
2. **原文**：“坤元合德機緘通，五氣偏全定吉凶。”
   **白话**：书中把五行之气的偏全与天地配合作为判断线索；“吉凶”只保留为原书术语。
3. **原文**：“何處起根源，流向可方住，機括此中求，知來亦知去。”
   **白话**：分析作用链时，要找出源头、流向与停止之处。这里依所据页面原字转录，“流向可方住”疑有传抄或录入异文，不擅改正文。
4. **原文**：“天道有寒暖，發育萬物，人道得之，不可過也。”
   **白话**：寒暖是观察环境节律的一项维度，重点在不过度偏向一端。
5. **原文**：“甲木參天，脱胎要火，春不容金，秋不容土，火熾乘龍，水蕩騎虎，地潤天和，植立千古。”
   **白话**：书中用甲木说明同一五行在季节、根基和制化条件不同的时候，不能采用同一套结论。

## 可应用规则

1. **时令证据提示**
   条件：月令及节气换算已经确认。
   → 提示：“可按《滴天髓》的文化视角，先列出得时证据，再与根气、透干、制化证据并看。”
2. **旺衰证据分列**
   条件：需要描述某一五行的状态。
   → 提示：“请分别展示得时、得地、得助、受泄与受制，避免只按数量判定旺衰。”
3. **流通路径提示**
   条件：盘中存在连续的生克关系。
   → 提示：“可标出‘源头 → 中继 → 落点/阻点’的关系链，作为结构参详，不推导必然事件。”
4. **寒暖燥湿提示**
   条件：季节与组合呈现明显寒、暖、燥或湿的倾向。
   → 提示：“可另列寒暖燥湿维度，并说明它与旺衰、流通是并列证据，不以单项覆盖全局。”
5. **干性名论提示**
   条件：引用十干章节的譬喻。
   → 提示：“十干句诀是古籍的象征语言；需结合季节和全局说明，不直接映射性格、健康或职业。”

## 不可应用清单

- 不输出生死、疾病、灾祸、贫富或社会地位的确定性断语。
- 不把五行偏全当作现代医学、心理学或人格测评结论。
- 不以“补某五行”为由推荐医疗、投资、搬迁、改名或消费决策。
- 不把古例中的阶层、性别和伦理评价用于现代用户。
- 不把网页注释中的例断混作《滴天髓》口诀原文。
