# 《穷通宝鉴》蒸馏文档

## 概览
- 成书年代：清代（约公元17-19世纪）
- 作者：余春台（整理编纂）
- 地位：调候用神理论的专著，被誉为"调候用神之圣经"，系统阐述了五行在不同季节的旺衰状态及调候方法
- 特点：以十天干配合十二月令，详细论述各干在各月的旺衰状态及所需调候用神

## 核心方法蒸馏

### 调候用神判定逻辑
- 基本原则：寒需暖、暖需凉、湿需燥、燥需润
- 季节对应：
  * 正月（寅月）：木旺，宜火调候
  * 四月（巳月）：火旺，宜水调候
  * 七月（申月）：金旺，宜水火调候
  * 十月（亥月）：水旺，宜火调候

### 十天干调候逻辑
- 甲木：生于冬月需丙火暖局，生于夏月需壬水润局
- 乙木：生于冬月需丙火，生于夏月需癸水
- 丙火：生于冬月需甲木生扶，生于夏月需壬水调候
- 丁火：生于冬月需甲木，生于夏月需庚金发水源
- 戊土：生于夏月需壬水，生于冬月需丙火
- 己土：生于夏月需壬水，生于冬月需丙火
- 庚金：生于夏月需壬水，生于冬月需丁火
- 辛金：生于夏月需壬水，生于冬月需丁火
- 壬水：生于夏月需庚金发水源，生于冬月需戊土制水
- 癸水：生于夏月需庚金，生于冬月需戊土

### 调候优先级逻辑
- 第一优先：调候用神（解决寒暖燥湿问题）
- 第二优先：格局用神（解决格局成败问题）
- 第三优先：扶抑用神（解决身强身弱问题）

## 可应用规则

1. **调候优先规则**：
   - 条件：命局存在明显寒暖燥湿失衡
   - 提示格式："生于[月份]，[寒/暖/燥/湿]，首取[调候用神]为用，次取[格局用神]"

2. **甲木调候规则**：
   - 条件：甲木日主生于冬月（亥子丑）
   - 提示格式："甲木冬生，寒气逼人，首取丙火暖局，次取壬水润局"

3. **丙火调候规则**：
   - 条件：丙火日主生于冬月（亥子丑）
   - 提示格式："丙火冬生，寒湿困火，首取甲木生扶，次取丙火助身"

4. **戊土调候规则**：
   - 条件：戊土日主生于夏月（巳午未）
   - 提示 format："戊土夏生，火炎土燥，首取壬水润局，次取辛金生水"

5. **庚金调候规则**：
   - 条件：庚金日主生于夏月（巳午未）
   - 提示格式："庚金夏生，火炼真金，首取壬水润局，次取癸水调候"

6. **壬水调候规则**：
   - 条件：壬水日主生于冬月（亥子丑）
   - 提示格式："壬水冬生，水势泛滥，首取戊土制水，次取丙火暖局"

7. **调候组合规则**：
   - 条件：调候用神与格局用神冲突
   - 提示格式："调候[用神]与格局[用神]冲突，宜[调候用神]为先，[格局用神]为次"

8. **调候应期规则**：
   - 条件：大运流年引动调候用神
   - 提示格式："大运/流年[五行]，引动调候[用神]，主[吉凶特性]"

## 公版原文引录

1. "春木有水方荣，夏木无水则枯。"（春天的木有水才能繁荣，夏天的木没有水就会枯萎）
2. "秋金得水方精，冬金无火则寒。"（秋天的金得到水才精纯，冬天的金没有火就寒冷）
3. "夏火逢水既济，冬火遇木温暖。"（夏天的火遇到水达到平衡，冬天的火遇到木就温暖）
4. "土旺四季，最怕木克；土居中央，喜火相生。"（土在四季都旺，最怕木克；土居中央，喜欢火相生）
5. "金水相涵，清白可贵；火土相生，厚重有成。"（金水相涵，清白可贵；火土相生，厚重有成）
