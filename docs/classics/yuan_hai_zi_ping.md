# 《渊海子平》蒸馏文档

## 概览
- 成书年代：宋代（约公元10-13世纪）
- 作者：徐子升（相传）
- 地位：八字命理学的奠基性著作，被誉为"八字之祖"，确立了八字排盘、十神、格局等基本理论框架
- 特点：系统阐述了日干与其他干支的关系，提出了"用神"概念，强调格局成败对命运的影响

## 核心方法蒸馏

### 八字排盘基础
1. 年柱：以立春为界，非农历正月初一
2. 月柱：以节气为界（如立春、惊蛰等），非农历月份
3. 日柱：以子时开始，非午夜
4. 时柱：以真太阳时为准

### 十神关系判定逻辑
- 正官：克我者，阴阳相异
- 七杀：克我者，阴阳相同
- 正印：生我者，阴阳相异
- 偏印：生我者，阴阳相同
- 正财：我克者，阴阳相异
- 偏财：我克者，阴阳相同
- 食神：我生者，阴阳相异
- 伤官：我生者，阴阳相同
- 劫财：同我者，阴阳相同
- 比肩：同我者，阴阳相异

### 格局判定逻辑
- 正官格：月支为正官，且无伤官破坏
- 七杀格：月支为七杀，有制化（食神制杀或印星化杀）
- 财格：月支为财星，身强能担财
- 印格：月支为印星，身弱得生扶

## 可应用规则

1. **用神选择规则**：
   - 条件：日主弱则取印比为用，日主强则取财官食为用
   - 提示格式："日主[强/弱]，宜[印/比/财/官/食]为用，忌[克泄耗]"

2. **格局成败规则**：
   - 条件：正官格见伤官则破格，七杀格见食神制则成格
   - 提示格式："[格局名称]见[破坏因素]则破格，见[成格因素]则成格"

3. **调候规则**：
   - 条件：冬生需火暖局，夏生需水润局
   - 提示格式："生于[季节]，宜[调候用神]调候，忌[相反五行]"

4. **通关规则**：
   - 条件：官杀混杂需印星通关，财星坏印需比劫护印
   - 提示格式："[矛盾组合]，宜[通关用神]通关，忌[破坏因素]"

5. **病药规则**：
   - 条件：命局有病（过旺/过弱/受克）需药（用神）治疗
   - 提示格式："命局[病状]，宜[药]治之，忌[加重病状]"

6. **岁运应期规则**：
   - 条件：大运流年引动用神则吉，引动忌神则凶
   - 提示格式："大运/流年[五行]，引动[用神/忌神]，主[吉凶]"

7. **十神组合规则**：
   - 条件：正官+正印=官印相生，七杀+食神=杀印相生
   - 提示格式："[十神1]+[十神2]=[组合名称]，主[吉凶特性]"

8. **特殊格局规则**：
   - 条件：从格、化格等特殊格局需全局判断
   - 提示格式："全局[特征]，可论[从格/化格]，宜[相应用神]"

## 公版原文引录

1. "八字者，干支是也。支中所藏者，天干之气也。"（八字就是天干地支，地支中所藏的是天干之气）
2. "用之为物，不可损伤；不用之物，尽可毁之。"（用神不可损伤，不用之物可以毁掉）
3. "有病方为贵，无伤不是奇。"（命局有病才有贵气，没有损伤不算奇特）
4. "官杀混杂，须要制伏；印星被伤，最怕财星。"（官杀混杂需要制伏，印星被伤最怕财星）
5. "财官印食，四者为用；杀伤劫比，四者为忌。"（财官印食为用神，杀伤劫比为忌神）
