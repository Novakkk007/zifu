# 《三命通会》蒸馏文档 · 格局篇（六格构成与成败）

## 概览
- 成书年代：明代（约万历年间）
- 作者：万民英（字汝豪，号育吾）——明代子平命理集大成者
- 地位：研究子平术的「集大成」著作，兼收宋以来诸家之说，体系博杂而资料最全；其中「论正官」「论七杀」「论财」「论印绶」「论食神」「论伤官」等篇，为其「格局」系统的代表章节，与《渊海子平》《子平真诠》同属子平派公版格局框架。
- 公版来源：`https://zh.wikisource.org/wiki/三命通會`（维基文库，公版原文卷次目录，200 可达、正文含「万民英」著者，本蒸馏以其中「格局」相关篇目为基准；正文分卷，格局篇见卷九之后各「论 X」章）

## 核心方法蒸馏：六格构成与成败

> 说明：子平「六格」（正官、七杀、财、印绶、食神、伤官）的「以月令取用、以成败救应论贵贱」框架，是《三命通会》诸「论X」篇与《子平真诠·论用神成败救应》所共享的公版通识。以下按该公版通识整理，原文依据取本仓库已收录的《子平真诠》公版文本（`docs/classics/absorbed-bazi-repo/zipingzhenquan.md`，同源框架），不编造《三命通会》独有条文。

### 取格总则
- **专主月令提纲**：八字入手，先看生月（月令）所藏，以为格局用神之根；月令无可用神时，再于四柱另寻财官煞食透干会支者取用（建禄月劫之格）。
- **成败救应为纲**：格局有「成」「败」，成者贵、败者贱；成中有败（带忌）、败中有成（救应），皆可细判。

### 六格构成条件（以月令取用）
| 格局 | 成格条件（概要） | 败格条件（概要） |
|---|---|---|
| **正官格** | 官逢财印，更无刑冲破害，为成 | 官逢伤官、被克刑冲，为败 |
| **财格（正财/偏财）** | 财生官旺；或财逢食神生，身强带比；或财格透印而位置妥贴、两不相克 | 财轻比重；或财透七杀，为败 |
| **印格（正印/偏印）** | 印轻逢官杀；或官印双全；或身印两旺而用食伤泄气 | 印轻逢财损；或身强印重而透杀，为败 |
| **食神格** | 食神生财；或食带七杀而无财而透印护食 | 食神逢枭神夺食；或生财露杀，为败 |
| **七杀格（煞格）** | 身强、七杀逢制（食神制杀），为成 | 七杀逢财而无制，为败 |
| **伤官格** | 伤官生财；或伤官佩印而伤旺印有根；或伤旺身弱而透杀印 | 伤官见官（非金水伤官）；或佩印而伤轻身旺，为败 |

### 成败救应细则（公版通识摘要）
- **遇伤解伤**：官逢伤官，透印以解之。
- **杂杀清格**：正官杂合杀，合杀以清之。
- **刑冲会合解**：刑冲而会合以解之。
- **劫财化伤**：财逢劫财，透食神以化之、生官以制之。
- **印制泄气化劫**：印逢财，劫财以解之，或合财而存印。
- **枭夺食救**：食神逢枭，弃食就杀以成格，或生财以护食。
- **杀印救应**：杀格逢食制而印来护杀，逢财以去印存食。
- 总旨：「八字妙用，全在成败救应，其中权轻权重，甚是活泼。」——不作僵化断言，以单一例证论成败。

## 可应用规则

1. **格局取用规则**：
   - 条件：日主以月令为根，辨六格（正官/七杀/财/印/食神/伤官）之一为主格
   - 提示格式：「[格名]格：以月令[所藏]为用，主[格局主象]，宜[成格条件]，忌[败格条件]」

2. **成格参考规则（文化提示，不作后果断言）**：
   - 条件：正官格而官逢财印、无刑冲破害
   - 提示格式：「正官逢财印相护，格局较清正——文化象征：端庄守序之象」

3. **败格警戒规则（只提示、不下吉凶断语）**：
   - 条件：某格成立但逢明显破败条件（如财格逢七杀）
   - 提示格式：「[格名]逢[破败因]，参考古籍多以此为破——文化象征：宜留意其反作用力，不作决定论」

4. **救应参考规则**：
   - 条件：格局带忌，但另有干支能「救应」（解伤/清杀/会合解冲）
   - 提示格式：「虽带[忌]，得[救应]可化——传统视为有转圜余地，宜以实际情况为准」

5. **多格相参规则**：
   - 条件：四柱透出多格（如官印双全、食伤带财）且配置妥贴
   - 提示格式：「[甲格]与[乙格]相参，配置妥贴，传统谓[双全]——文化象征，不作命运定数」

## 公版原文引录（均取自本仓库已收录公版文本，可溯）

1. 「用神专寻月令，以四柱配之，必有成败。」（《子平真诠·论用神成败救应》）
   **白话**：格局用神专从月令寻取，再配四柱干支看它的成败。

2. 「何谓成？如官逢财印，又无刑冲破害，官格成也。」（同上）
   **白话**：什么叫成格？如正官逢财与印相护，又没有刑冲破害，这就是正官格的成功形态。

3. 「何谓败？官逢伤克刑冲，官格败也。」（同上）
   **白话**：什么叫破格？官星逢伤官、受刑冲破害，正官格就破了。

4. 「八字妙用，全在成败救应，其中权轻权重，甚是活泼。」（同上）
   **白话**：八字的高妙在于成败与救应，其中轻重权衡非常灵活，不可执一。

5. 「印绶遇官，此谓官印双全，无人不贵。」（《子平真诠·论印绶》，同源公版框架。注：此为子平公版通识的表述，与《三命通会》得官印相生之旨一致）
   **白话**：印绶遇正官，这叫官印双全，传统上以此为大贵之象。

## 不可应用清单

- **不作生死病灾断言**：格局成败只作「文化象征 / 参考维度」提示，绝不据此断吉凶祸福、寿命、婚嫁成败。
- **不执一于单一格**：公版通识明言「权轻权重，甚是活泼」，六格中兼格、变格、连格众多，严禁以单一格局机械结论。
- **不冒充《三命通会》独有条文**：本蒸馏所用成败通识同时见于《渊海子平》《子平真诠》等子平公版框架，不把子平框架语录误标为《三命通会》原文字句——需确切《三命通会》原文时，以维基文库分卷篇目（论正官/论七杀/论财/论印绶/论食神/论伤官）为准。
- **不把格局与「现实人生结果」一一对应**：正官/财印等只是传统文化符号，非现实身份/财富/职位的直接镜像。
