# 《果老星宗》蒸馏文档

## 概览

- 书名：传世本常见《果老星宗》，公版来源页题作《张果星宗》。
- 作者与朝代：旧题唐代张果。现存文本层次复杂，含后世汇编、注释与增补痕迹；“张果”应视为传统托名，不据此认定全书由唐人一时写成。
- 成书背景：该书汇集传统星命术的入门起例、历法与星曜行度、十二宫、二十八宿、七政四余、宫度关系、原盘与行限等材料，是中国传统星命体系的综合性传本。
- 公版状况：本次仅使用维基文库标为 `PD-old` 的《张果星宗》正文。古籍本体已进入公版；现代整理本的标点、校注、译文与版式仍可能另有权利，因此不复制现代出版物内容。
- 使用定位：下文只把原书整理为历史文化知识和可解释的数据结构，不把星命术包装成天文学事实，也不提供现实决策或个人命运指导。

## 核心方法蒸馏

### 排盘前提：时间、历法与星度

原书先列年、月、日、时的起例，再列太阳、太阴及诸曜行度。其结构意味着：时刻、历法和星度是后续宫位解释的输入，而不是可以由吉凶断语反推的结果。工程实现若缺少可靠出生时刻、地点、时区或星历，就应停在资料说明层，不补造精确盘位。

### 十二宫与二十八宿是两层坐标

- 十二宫提供主题分区，例如命、财帛、田宅、官禄、福德等；宫主用于描述星曜与宫分的对应。
- 二十八宿及其度数提供更细的定位；度主与宫主可能不是同一颗星。
- 原书明确把“论宫”和“论度”并列，因此不可只凭宫名或只凭宿度输出结论。工程上应分别保存宫、宿、度及边界误差，再展示二者如何组合。

### 七政四余与关系网络

- 七政指日、月和木、火、土、金、水五星。
- 四余通常指紫气、月孛、罗睺、计都，是传统历算和星命语境中的对象；它们不应全部等同为现代天文学的实体行星。
- 原书除星体自身位置，还考察守、会、朝、拱、夹、引、从等关系，以及入垣、升殿、强弱等传统状态。蒸馏时应把这些拆成“对象—位置—关系—传统评价”四层，避免把单星固化成恒定吉凶标签。

### 原盘与行限分层

原书以“体”称原守星盘，以“用”称流行星度和限年。可将其理解为静态出生盘与动态时间层的区分。二者可以关联展示，但不得把后来的流年因素倒写成出生盘事实，也不得将传统应期直接转成现实事件预测。

### 身宫、命宫与紫府（紫微斗数）派别的异同

| 维度 | 《果老星宗》体系 | 紫府所用紫微斗数体系 |
| --- | --- | --- |
| 共同点 | 都以十二宫组织人生主题，也都把命宫、身宫作为重要观察点 | 同左 |
| 主要星曜 | 以七政四余为核心，并结合二十八宿、宫主、度主及星曜行度 | 以紫微星系等斗数星曜及其安星规则为核心 |
| 坐标重点 | 黄道十二宫与二十八宿度数并参，宫与度须分层记录 | 十二地支宫位、宫干与斗数星曜组合为主要表达层 |
| 命身解释 | 命、身要与其宫度、主星及会照关系合看 | 命、身要与斗数宫位、主辅杂曜及四化等规则合看 |
| 工程边界 | 不把星宗的宫主、度主或七政四余直接套入斗数规则 | 不把斗数星曜或四化反向解释为星宗星度 |

两套系统有同名宫位，不代表计算过程或语义完全相同。跨派展示只能做概念对照，不能把一派结论当作另一派的校验答案。

## 可应用规则

以下规则只生成传统文化型提示，供日后编码进 `masters-rules`；不生成具体行为指导。

1. **输入完整性门槛**
   条件：出生时刻、地点、时区、历法换算或星度数据任一项缺失或精度不足。
   → 提示：“《果老星宗》先定历法与星度；当前资料不足，仅介绍相关术语，不作精细宫度解读。”
2. **宫度双层展示**
   条件：某星已得到宫位与宿度数据。
   → 提示：“传统星宗同时论宫与论度；请分列宫主题、宿度位置及边界误差，避免单层定性。”
3. **七政四余对象标注**
   条件：输出涉及气、孛、罗、计。
   → 提示：“这些名称属于传统七政四余体系，不等同于四颗现代实体行星；此处仅作历史文化说明。”
4. **静态与动态分层**
   条件：原盘信息与行限、流年信息同时出现。
   → 提示：“原书以‘体’区分原盘、以‘用’区分流行层；两层分别展示，不把动态因素写成先天事实。”
5. **关系优先于单星标签**
   条件：某颗星被单独标为吉或凶，但尚未检查守、会、拱、夹及宫度状态。
   → 提示：“单星标签不足；依传统文本补列位置、状态和关联关系，并保留相反证据。”
6. **命身联合但不合并**
   条件：同时取得命宫、身宫及各自主星关系。
   → 提示：“命宫与身宫是不同观察点；并列说明其传统象征，不合并为单一人格或命运结论。”
7. **跨派隔离**
   条件：将星宗命身宫与紫微斗数同名宫位对照。
   → 提示：“两派共享部分宫名，但星曜、坐标和安置规则不同；本对照只说明概念相似处，不互相代算。”
8. **古代断语降级**
   条件：原文涉及贵贱、贫富、寿夭、疾病、婚育或刑罚等断语。
   → 提示：“这是古代社会语境中的分类语汇，仅标注其文献背景，不映射为现代个人评价或事件预测。”

## 公版原文引录与白话对照

以下均据来源页正文抄录；每条原文不超过 80 字，标点沿用页面文本。

1. **原文**：“此为宫分相合以布七曜。”
   **白话**：十二宫的所属关系，是布列和理解七曜的一层框架。
2. **原文**：“此为度宿所属以布七政。”
   **白话**：二十八宿的度数归属，是定位七政的另一层框架。
3. **原文**：“体者，静也，又曰原守星盘，排下七政四余原。”
   **白话**：“体”指相对静态的原始星盘，以七政四余构成出生层信息。
4. **原文**：“用者，动也，又曰流行周天行度。”
   **白话**：“用”指随时间变化的运行度数，应与原盘分层处理。
5. **原文**：“会者，诸星聚一宫一度也。”
   **白话**：“会”描述多颗星集中于同一宫度的关系，不能脱离其他条件单断。
6. **原文**：“正垣者，论宫；偏垣者，论度。不论安命行限，皆准此例。”
   **白话**：宫与度是并列的观察维度，无论安命还是讨论行限都不能偏废。

## 不可应用部分

- 不用星盘预测死亡、疾病、灾害、刑罚、官职、财富、考试、婚育或任何具体事件。
- 不依据命宫、身宫、星曜或传统煞名评价人的道德、智力、外貌、性别角色、阶层或人生价值。
- 不把七政四余的传统对应宣称为现代天文学、医学、心理学或因果科学。
- 不在时刻、地点、时区、历法或星历缺失时补造盘位，也不掩盖宫界、宿度边界的误差。
- 不将《果老星宗》旧题张果当作已经证实的作者结论，不把后世汇编层一概归为唐代原文。
- 不复制仍受版权保护的现代校注、译文、排版、数据库或商业软件规则；本文件的白话说明均为重新表述。
- 不采用来源页中缺字、乱码或校勘不明的句子；遇版本异文时只记录差异，不自行补字。
