# 先生谈岁运

年轻人来喝茶，常把“大运流年”四个字问得很重，仿佛一翻命书，十年吉凶便已钉死。其实不必如此。按子平家的说法，出生时的四柱像一张时令与禀赋的底图；大运，是这张图在较长年月里所遇的气候；流年，则是每一年更细的一阵风雨。古人以一个干支统摄一段约十年的行程，接续排去，称为“一步运”。这个“步”字用得很有人情味：它不是判词，而是脚下的路程；一步有一步的景，一程有一程的课。有人逢顺风，便适合张帆，却仍要会掌舵；有人暂走山路，也可借机练脚力、辨方向。大运与流年相逢，像季节又碰上天气：春日未必天天暖，冬日也并非没有晴光。读岁运，真正可取的，是看何时宜进、何时宜守，什么长处容易施展，什么习惯需要照看。它给人的应当是准备，而不是恐惧。命理若只剩“必然发生什么”，便把活生生的人看窄了；人的选择、学识、关系与担当，同样日日在改写处境。茶凉了可以再续，路远了可以缓行。年轻人，记住这一句便好：路有它的来处，走法仍在你的脚下。

# 神煞是什么

旧命书里常见天乙贵人、桃花、驿马，名字又亮又响，初读的人难免以为，命盘里真站着几位神将，专管福祸。其实“神煞”更像古人留下的一套文化符号。先民观星候气，把天象、节令与人间经验互相参照；后来术数家又借官署、道路、花木等日常意象，为干支之间某些组合取名，便于记忆，也便于说理。天乙贵人借“贵助”之象，提醒人在某些关系里较易得扶持；桃花沿用咸池、沐浴一类古老意象，常被拿来谈人缘、审美与情感显露；驿马取自驿站奔走，所指多是迁动、远行与环境转换。可见这些词首先是比喻，不是藏在天上的判官。同一个驿马，对求学者可能是异地见闻，对从业者可能是差旅变动；一处桃花，也可以表现为亲和、才艺或公众缘分，不能只往情事上猜。古人建立符号，是为了把复杂经验说得简明，我们今天读它，更要把符号还原成处境，再与全局、时代和个人选择互相印证。若见“贵人”便坐等相助，见“煞”便惶惶不安，反倒失了读书的本意。神煞可以是一盏提示方向的小灯，却不是替你裁决人生的大印。借古人的象，照自己的心，才算把这套语言用活了。金句：象可供人观，命不可由象判。

# 读《子平真诠》

《子平真诠》是清人沈孝瞻所著，论子平法条理严整，后世常把它视作研习格局、月令的一部正脉读本。书中有一句要紧话：“八字用神，专求月令。”初见“用神”二字，容易想成某种神秘力量；在这部书的语境里，它首先是判断一局气势如何组织、何处可以着力的枢纽。为什么“专求月令”？因为月支标示出生时的季节，是全局旺衰寒暖最先要看的背景。譬如同是一株木，生在春令，得时舒展；生在严冬，先要顾寒冻；到了燥秋，又须察金气与水润。木还是木，处境不同，安排便不能照抄。所谓从月令求用，不是只看一个字便下结论，而是先抓住季节这个总纲，再看天干有没有透出、地支有没有根气，彼此是扶助、制约，还是转化。好比进屋先辨梁柱，再看门窗陈设，次序清楚，便不易被零碎的吉凶名词牵着走。更可贵的是，这种读法教人尊重条件：任何性情与才具，都要放到具体环境中理解；所谓“有用”，也不是永远不变，而是能否在当下使全局较为协调。读古书不必把每句话奉为铁律，却可学它如何立纲、如何推理、如何从纷繁处找主线。金句：识月令，是先知四时；求用神，是再问一身如何成其材。
