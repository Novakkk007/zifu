## 吸收内容

把跃渊的「研究程序纪律」与「证据分级」方法论抽象为一层工程纪律，补充到先生落地的工程要求里：

1. **证据分级 + 规则层级透明**：
   - 输入可信度 S0–S3，推理证据 A–E 分开标注；禁止把解释伪装成事实
   - 规则层级 STRUCTURAL > CORE > SCHOOL > HEURISTIC > SUPPLEMENTAL，流派分歧显式标注、不混用
2. **预注册 + 后验**（研究程序最核心）：结论是「验证出来的」不是「算出来的」——先锁定预测，再用经历做命中/部分/未命中/未知四态裁决，不反向篡改
3. **允许不确定、拒绝迎合**：存在路线级分歧时并列两条相反路线并给判别年份；用户说「某年很顺」不会让系统改口
4. **应期只给候选窗口 + 判别年份**：信号链（前置断时段、完成断年份），多重独立信号互证，不宣称确定年份
5. **结论带证据等级与规则层级**，不做伪量化（只给「倾向 + 程度」，不强行二选一）
