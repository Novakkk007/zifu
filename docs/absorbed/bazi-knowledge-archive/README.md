# 八字知識庫

本分支是從 `liuyao-divination-archive` 分離出的八字資料，可直接下載後建立全新的八字 repository。

## 資料夾結構

```text
├── 00_index/              八字索引與總導覽
├── 01_foundation/         八字基礎概念
├── 02_ten_gods/           十神系統
├── 03_stems_branches/     天干地支、藏干、刑沖合害
├── 04_pattern_structure/  格局、旺衰、用神喜忌
├── 05_luck_cycles/        大運、流年、流月
├── 06_question_types/     八字問事分類
├── 07_reading_templates/  八字解析模板
├── 08_case_archive/       八字案例與回饋
└── 99_sources/            八字來源資料
```

## 使用原則

八字分析以日主為核心，先看月令，再看旺衰、格局、用神、喜忌，最後配合大運流年；古文重語應降火修正，不以單一十神或格局硬斷吉凶。
