## 吸收内容

把 MingLi-Bench 的「评测方法论」抽象为一套自测评估先生质量的办法，供先生落地后的效果验证参考：

1. **排盘与推理解耦**（最关键条款）：
   - 先由确定性引擎排盘并作为固定输入注入，模型不再自行从生辰推四柱/大运
   - 使评测分数反映「推理/论断质量」而非「排盘准确度」——排盘准确度已由对拍审计覆盖
2. **选择题形式 + 答案完全一致**为评分标准，避免自由文本评分的主观性
3. **事件分类落地**：事业、健康、婚姻、子女、学业、官非、家庭、性格、灾劫、财运、运势等维度逐类评估，暴露相对短板
4. **CoT（思维链）默认开启**：让模型先推演再作答，中间过程可审计
5. **可重复性**：固定 seed/温度 0、输出结构化结果，便于纵向对比版本间先生是否有退化
