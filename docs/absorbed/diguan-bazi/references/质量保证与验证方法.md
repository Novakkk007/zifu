# bazi-master 质量保证与验证方法

> 本文档记录在 bazi-master-skill 开发和维护过程中建立的验证方法论。
> 每次修改排盘算法、调候表、或论命规则后，必须按此流程验证。

## 排盘算法验证

### 日柱交叉验证

日柱是最容易出错的环节。修改日柱相关代码后必须执行：

```bash
# 单日期验证
python3 scripts/verify_pillars.py --date YYYY-MM-DD

# 批量验证（至少覆盖以下范围）
python3 scripts/verify_pillars.py --count 50
```

验证要点：
- 覆盖多个年代（1950s-2020s，至少6个年代）
- 覆盖闰年边界（2000-02-29、2004-02-29、1996-02-29）
- 覆盖世纪年（2100-03-01，非闰）
- 交叉比对独立算法（高氏日柱公式）

### 四柱完整验证

随机生成10组以上不同年月日时+不同城市经度的案例，验证全部四柱：
- 年柱：验证立春边界判断（如1964-01-24在立春前→用1963年干支）
- 月柱：验证节气区间+五虎遁
- 日柱：交叉比对
- 时柱：验证真太阳时→时辰+五鼠遁

### 真太阳时验证

检查极端经度偏移（乌鲁木齐-130分、拉萨-116分）下的时辰是否正确。

## 调候表验证

修改附录A调候速查表后：

1. **逐条比对**：120条 vs 徐乐吾注本原文。重点关注第一调候。
2. **学者交叉验证**：梁湘润、何重建等现代学者的整理版用于交叉验证。
3. **版本差异记录**：任何与通行版的差异必须在「附录A附」中记录，标注学者观点。
4. **抽验**：修改后随机抽20条（25%），逐条对照徐注原文验证。

## 场景参数化规则验证

新增或修改场景分流规则后：

1. **覆盖检查**：确认该断语在第三章或第五章有对应的分流表
2. **场景完整性**：每条断语至少覆盖3个现代场景
3. **措辞检查**：确认禁用词表（5.11节）已覆盖所有封建/侮辱性用语
4. **交叉引用**：确认分流表引用的手册章节号正确

## 文件一致性检查

每次修改后：
- `SKILL.md` 的能力清单是否指向所有新增模块
- 桌面副本与源目录 `md5sum` 完全一致
- `find` 对比两边文件数一致
- 无残留的已合并/已删除文件引用
