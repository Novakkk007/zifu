# 谛观·八字 diguan·bazi

> 承八部古籍之精要，断千载未决之疑章。不论虚表，只推真机。

## 缘起

子平之术，传世千年。渊海子平立其基，子平真诠定其格，滴天髓阐其微，穷通宝鉴明其候，神峰通考验其真，三命通会集其成，千里命稿理其序，李虚中命书溯其源。

八部经典，各有所长，亦各有所执。有云「官杀混杂必凶」，亦有云「官杀混杂富贵甚多」。有云「伤官伤尽大贵」，亦有实战大家直言「但有贫贱，并无富贵」。有云「调候为急」，亦有云「格局为先」。

孰是孰非？

不对校，只堆砌，便是知识库。对校过，裁决过，才敢称**论命**。

本技能不做知识罗列。八部经典，逐条交叉验证。诸书分歧，逐一裁决到底——全书共 **21 条分歧裁决**，每条附双方出处和判决理由。古籍中上百条推演规则已全部落成可追溯的因果链——断则断透，不和稀泥。

## 声明

**本技能（diguan·bazi）为传统学术研究工具，面向易学研究者、八字术数学者及传统文化爱好者。**

本项目汇通了子平术中多个流派的核心方法论——渊海子平的外格体系、子平真诠的格局法、滴天髓的病药说与从化论、穷通宝鉴的调候体系、神峰通考的实战验证——而非偏执一宗一派。各流派之间的方法论冲突已通过交叉验证和逐条裁决完成融合，形成了一套可追溯、可验证的推理体系。

⚠️ **使用限制：**
- 仅供学术研究、教学参考、个人学习使用
- **不得用于任何商业算命、收费预测、封建迷信活动**
- 本系统不替代专业心理咨询、医学诊断或法律建议
- 使用者须自行遵守所在地法律法规

本项目的价值在于**方法论**——如何将多流派冲突的古典知识整合为可操作的推理系统，而非"算得准不准"。

## 能做什么

- **排盘**：提供出生时辰与地点 → 推真太阳时、定节气交节、排四柱八字、起大运流年
- **论命**：格局成败、旺衰强弱、用神选取、调候配合、大运流年应期 —— 逐层推理，一气贯通
- **垂询**：事业穷通、财富厚薄、婚姻良莠、健康损益、学业进退，按需定焦
- **现代分流**：所有古典断语均经「现代场景参数化」处理——将"伤官见官，为祸百端"按体制内/私企/创业/自媒体/学术等 7 种场景分别判断，不拿古人的尺子量今人的路

无需冗长问卷，无需反复填表。开口即算，算则见底。

## 技术特点

### 古典融合
- **八部古籍合编**：渊海子平、子平真诠评注、滴天髓阐微、穷通宝鉴、神峰通考、三命通会、千里命稿、李虚中命书
- **21 条分歧裁决**：逐条列出争议双方出处、最终裁断及理由
- **if-then 规则化**：古籍中的推演规则全部转化为可执行的条件判断链

### 现代适配
- **十神场景重映射**：官/财/印/食伤/比劫在数字时代的含义重新锚定
- **核心断语分流**：13 条高频古典断语按多种现代场景分别判断
- **措辞现代化**：禁用"克夫""淫乱""短命""妾"等封建/恐吓性用语

### 计算引擎
- **纯 Python 标准库**，零外部依赖
- **真太阳时**：经度时差 + 均时差（EoT）
- **节气精算**：2000-2100 年完整节气表，离线可用
- **日柱验证**：基点法 + 高氏日柱公式双算法交叉验证，1984-2043 年 21915 天全部通过

## 三则

**其一，断则断透。** 不给「可能 A 也可能 B」。每条判断有书可证，有据可查。古籍怎么说的，哪本书跟哪本书打架了，怎么裁决的，裁决理由是什么——逻辑链完整，不跳步。

**其二，知止不妄。** 子平八字是分类器，不是放大镜。算得了格局高低，算不了明年银行卡余额。算得了健康倾向，算不了哪天生病。越界之问，直言其不可为，不编造。

**其三，古法今用。** 同一句断语，置于古代与置于今世，置于体制内与置于江湖，置于为人打工与置于自立门户——吉凶或可完全相反。时辰不变，世道已迁。
