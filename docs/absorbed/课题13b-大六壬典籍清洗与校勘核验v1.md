## 3. 校勘发现（第2段核心）
1. **《六壬大全》卷四标点本讹字**：作「丙戊课**己**不须论」，而卷一入手法作「丙戊课**巳**」。按「分明不用四正神」之例（四正=子午卯酉，寄宫只用四隅与辰戌），定作**巳**。→ 已写入引擎校记。
2. **贵人歌字序**：原文「壬癸**蛇兔**藏巳卯」（巳蛇、卯兔），旧注作「壬癸兔蛇藏」。支序不变，算法结果一致；但引文须逐字照原文。
3. **原文疑讹字**：末句公版作「**六壬**逢马虎午寅」。按午马寅虎推之，当为「六**辛**逢马虎」，通行本同。此本「六壬」为刊刻之讹 → 引擎取六辛（现码 `辛:[午,寅]` 正确），讹字入校记。
4. **「中气换将」为算法自述非原文**：原文表述是「以月将加于正时」（dq_04）；月将换将依中气属算法约定，不宜挂在《六壬大全》出处下。→ 引擎 source 字段后续应区分「原文引文」与「算法约定」两类。
