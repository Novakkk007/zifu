# 课题04 · 问剑体系（对抗式进化训练框架）

> 来源：docs/duel/README.md + record.md + sample-answer.md + scripts/voice-duel.py
> 吸收日期：2026-09-15
> 课题类型：产品/方法论（非命理规则直接吸收，属于训练机制层）

## 一、新知要点

1. **对抗式进化方法论**七步赛制（立题→双盲立断→亮牌比照→分歧过招→复述确认→裁判→结算吸收）
2. **十维度对照检查表**：旺衰/格局/用神/十神心性/六亲/事业财/婚恋/健康/应期/取象
3. **经验卡三去向**：规则文档 docs/bazi-rules.md、引擎算法 contracts/engines/、解释框架 AI语料
4. **模块等级评估**：历法/大运/神煞/旺衰/格局/用神/断事/应期/取象/心性——甲完备→丁未建
5. **诚实边界**：求败、专挑吃不准案例、断不出记「未建」不硬编、不确定标「待考」
6. **语音链路实现**：听(funasr+VAD+术语纠错)→想(紫府人格+盘面注入)→说(say朗读)→存档(sessions/)
7. **ASR热词与纠错词典**：命理术语 hotword + FIX 映射（前灶→乾造、日烛→日主等）
8. **对战与现有体系衔接**：断命体系七步法对照、名家参详(SWH/LXR/LJM)回填、产品口径不变

| 双盲+密封+复盘 | 无 | **全新**：质量保障流程，与现有「批盘→校准」模式可互补 |

## 三、可规则化判断

- **contracts/engines/masters-rules/**：本次课题属「方法论/产品机制」，不直接产生命理规则，**暂不写入**引擎规则文件。
- **docs/bazi-rules.md**：十维度表可与现有断命体系对照合并，待人工审后统一。
