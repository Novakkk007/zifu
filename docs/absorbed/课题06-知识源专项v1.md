## 一、新知要点（12 条）

### （一）工程架构与纪律
1. **多 agent 分工定版（九角色）**：LEAD（Hermes 主脑：整合/门禁复跑/上传/初心检查）、GPT-6（严格审阅+设计定稿）、ALG（引擎/规则/对拍）、FE（视图）、CMP（文案/断语口径）、DATA（古籍结构化知识）、QA（测试）、COMP（合规）、VIS（视觉）；本吸收循环=LEAD 侧每日收罗执行。
2. **自动升级循环**：知识源增量→DATA 结构化→CMP 润色合规→QA 测试→FE 接线→GPT-6 抽审（大改）→门禁全绿→自动上传→日报 9:00；cron 计划：探讨轮周二五 20:00、日报 9:00、知识源增量轮每周一（待建）。
3. **红线四条**：引擎零篡改；测试只增不减；子 agent 自报不可信、主脑必复跑；文件边界并行（防空转）。
4. **知识分层铁律**：内部知识层（存原文/出处/规则 ID/审计链）≠ 展示层（一律「理解后的方式」：定义+现代释义+文化参详；零条文、零断言、零术语）。
5. **初心锚点**：卖点＝「照」不是「算」（被看见＞断得准）；每轮必检三问——更被看见？更诚实？守住初心？

### （二）古籍源核验（八字六书）
6. **六书全部实证可用**：滴天髓（维基文库；作者一律记「传为刘基撰」）；子平真诠（ctext wiki chapter=974137《子平真詮評注》；维基文库繁简均 404，勿再引）；三命通会；穷通宝鉴；渊海子平；神峰通考。命理约言待核验。
7. **核验方法（可复用）**：curl（UA 伪装+重试）→ HTTP 200 + 正文 grep 书名/作者/章名原字（防「200 空壳」/真页面挂假内容）→ 逐条记证据。
8. **引用纪律**：原字繁体不得「繁化简」冒充；徐乐吾评注不得反署沈孝瞻；旧蒸馏文档（渊海/神峰）疑似转写、引用前须对源页重验；三命通会不得以子平公版通识冒充独有条文。

### （三）解读知识 v1（滴天髓＋子平真诠）
9. **13 条术语定义深化**：三元/旺衰三证据/流通/寒暖燥湿/五气偏全/干支性情/用神/月令/格局/顺逆用/相神/有情有力/成败救应/纯杂——每条含定义→现代释义→文化参详→展示文案→内部溯源。
10. **3 组断语模板**（调候/格局/旺衰）：触发条件＋零断言句式＋每模板禁用清单（不转现实行为指导、不承诺结果、不映射命运）。
11. **14 条 C 组内部溯源表**（book+chapter+quote 繁体原字，2026-09-24 逐条实证）：「引文只许取自 C 表」白名单机制；附合规口径速查（忌词：灾/祸/血光/大难/必/注定/绝对；禁词替换表；句式三检）。
