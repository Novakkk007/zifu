# 蔡伯励 · 择日与堪舆方法论蒸馏

> 定位：本文只整理蔡伯励公开讲解中可复核、可描述为流程的通胜使用方法。天文历算可以提供确定的历日、节气和时区数据，但由这些数据推导吉凶属于传统民俗解释，并无现代科学预测效力。以下规则只适合生成带来源、可撤回的文化参详提示，不用于医疗、法律、投资、工程安全或其他高风险决定。

## 生平与体系概览

香港中文大学的院士赞辞与校方人物页可确认，蔡伯励生于 1922 年，是蔡真步堂天文历算第三代传人，长期参与编纂《真步堂通胜》；校方材料将该书概括为兼具排历与占测的历书。排历部分合用阳历、阴历、节气等时间资料，占测部分则叠加五行、八卦和传统宜忌。这里能确认的是传承、出版及内容结构，不能由“非物质文化遗产”身份推出择日结论具有科学效力。（来源 A1：https://www.cpr.cuhk.edu.hk/resources/press/pdf/5550489bd3634.pdf；来源 A2：https://www.iso.cuhk.edu.hk/chinese/publications/newsletter/article.aspx?articleid=61787）

蔡伯励在公开讲解中把《七政经纬历书》描述为需要多人计算日月五星位置、日月食等天文资料的专业历书，并把面向普通读者的通胜改成较易使用的每日等级和宜忌表。由此可把其体系拆成两层：一层是可校验的历法/时间数据，另一层是传统术数对这些数据所作的吉凶标注；两层不得在产品中混称为同等精度的“科学计算”。（来源 A3：https://www.master-insight.com/article/1785；来源 A4：https://www.master-insight.com/article/1796）

2019 年对蔡真步堂第四代传人蔡兴华的专访显示，通胜仍由家族成员合力编修，并以年度吉凶宜忌内容授权出版社。该材料适合佐证传承和编辑形态，不足以补出未公开的完整推算公式。（来源 B1：https://theinitium.com/20190202-culture-hongkong-traditional-calendar/）

## 核心方法论

### 1. 先分清“历法底座”与“术数解释”

**名称：** 历日排算—传统标注双层结构。

**逻辑链条：**

1. 先确定阳历日期、星期、农历日期、日干支、节气以及使用地点的时间；这些属于可以用历法库和时区数据库复核的数据层。
2. 再装载二十八宿、建除十二值、神煞、事项宜忌和吉日等级；这些属于特定通胜版本的传统解释层，必须携带版本、年份和来源。
3. 只对数据层使用“计算准确”一类表述；解释层统一标成“传统通胜参详”，不得让天文数据的可计算性为吉凶推断背书。

**适用场景：** daily-core 的数据模型和来源标识设计。当前引擎已经能计算干支、节气和 IANA 时区，但现有宜忌只是按日干的静态映射，并不等于蔡真步堂通胜的综合规则。

**蒸馏结论：** 蔡氏方法最适合映射成“可复核时间特征 → 有版本的传统规则 → 参详输出”三段式管线，而不是把历法与吉凶合成一个不可解释的分数。（来源 A1：https://www.cpr.cuhk.edu.hk/resources/press/pdf/5550489bd3634.pdf；来源 A3：https://www.master-insight.com/article/1785；来源 A4：https://www.master-insight.com/article/1796）

### 2. 普通用户先看综合等级，不从单一神煞重算

**名称：** 综合等级先行。

**逻辑链条：**

1. 编者先综合每日多个传统项目，再给出上吉、中吉、平吉等结果；蔡伯励公开说明的分段分别是 85–100、70–85、60–70。
2. 普通用户先以综合等级筛候选日，低于平吉的日期不进入推荐集。
3. 进入候选集后，再核对目标事项是否被明确列入“忌”，以及是否存在个人生肖相冲；后两者是排除条件，不因总分较高而自动失效。
4. 这些数值是蔡氏通胜内部的传统分级，不是统计概率，也不能在缺少真步堂原始计分表时由项目自行反推。

**适用场景：** 已取得合法、可追溯的真步堂年度数据时，对候选日排序和解释；不适合用自造权重冒充原版分数。

**蒸馏结论：** 面向用户的优先级不是“干支冲克 > 建除 > 二十八宿 > 神煞”的固定表，而是 `原版综合等级筛选 → 事项忌项复核 → 个人冲支排除`；公开材料不足以还原编者内部所有权重。（来源 A3：https://www.master-insight.com/article/1785；来源 A4：https://www.master-insight.com/article/1796）

### 3. 建除可作证据，二十八宿应降权

**名称：** 建除参照—宿值记录。

**逻辑链条：**

1. 蔡伯励介绍通胜版面时，列出每日干支、二十八宿和底部的建除十二值，并明确举出除、执、定为较好的日值。
2. 他同时表示二十八宿在其通胜中仍会列出吉凶，但在其讲解语境中主要为了保留记录，使用程度较低。
3. 因此建除和二十八宿都只能作为综合判断的输入或解释字段；不能像旧稿那样把十二值简单切成固定吉/凶三组，也不能把二十八宿切成普遍有效的“二十一吉、七凶”。
4. 若没有合法取得的年度通胜规则表，daily-core 只展示当日值名与来源，不生成事项级宜忌。

**适用场景：** 日历详情页的传统字段展示、综合规则的可解释证据；不适合单项“一票定吉凶”。

**蒸馏结论：** 在可公开核对的蔡氏讲解里，二十八宿的应用权重低于旧稿所写；建除也没有足够材料支持一套脱离事项和年度版本的统一吉凶表。（来源 A4：https://www.master-insight.com/article/1796）

### 4. 宜忌是事项过滤，不是把所有吉凶标签相加

**名称：** 事项白名单—冲突抑制。

**逻辑链条：**

1. 通胜会从大量传统事项中选列较重要项目；公开讲解举例涉及建屋、婚嫁、开市、安葬等。
2. 对某一目标事项，明确“忌”应阻止推荐；没有列入“忌”只表示该版通胜没有给出反对标记，不等于现实世界中安全、合法或必然有利。
3. 吉凶信号冲突时不能无条件累加。蔡伯励强调编者需要筛除相互冲突的组合，说明规则引擎必须有冲突检测、抑制理由和人工校勘来源。
4. 产品输出应同时显示命中的支持项、否决项和最终降级原因，避免只呈现“吉”的一侧。

**适用场景：** daily-core 后续的事项级 `yi/ji` 合并器和审计日志。

**蒸馏结论：** 可编码的重点是“显式忌项优先阻止推荐 + 矛盾证据降级”，而不是把吉神数量减去凶神数量后直接定性。（来源 A4：https://www.master-insight.com/article/1796）

### 5. 择时必须先做地点与民用时间归一

**名称：** 地点—时区—时辰边界校正。

**逻辑链条：**

1. 先读取事项发生地的 IANA 时区、经纬度和目标日期，处理当地夏令时与日期跨越。
2. 蔡伯励的公开讲解还使用每经度约四分钟的地方时修正，并建议避开时辰边界；这属于其择时口径，工程实现必须标注规则版本，不能与法定民用时间混淆。
3. 修正后的时间若落在两个时辰的边界缓冲区，输出“边界不确定/建议复核”，而不是强行归入吉时。
4. 这一步只保证输入时间口径一致，不能证明所谓星辰位置与人事吉凶存在因果关系。

**适用场景：** 跨地区择时与时辰显示。daily-core 已有 IANA 时区能力，但若要复现蔡氏口径，仍需显式的经度修正模式和边界策略。

**蒸馏结论：** 地点和夏令时不是择时完成后的附加信息，而是计算时辰前的输入；没有地点或时区的数据不得生成精确到时辰的参详。（来源 A4：https://www.master-insight.com/article/1796）

### 6. 堪舆材料只保留为不可编码的个案观察

蔡伯励公开谈香港风水时，主要使用山脉走向、水口、海面收聚等地形叙事，并叠加城市大运、立春四柱和五行解释。该材料能说明他会把形势观察与时间解释并参，却没有给出可复现的测量阈值、样本验证或通用算法。（来源 A5：https://www.master-insight.com/article/1804）

旧稿所写“风水效果独立于个人八字”在现有来源中找不到依据；同一材料反而同时使用地理形势和立春时点推演。因本卡目标是可对接 daily-core 的择日规则，所有龙脉、水口、城市地运、建筑布局和卫星地图推断均排除，不进入可应用规则。（来源 A5：https://www.master-insight.com/article/1804）

## 可应用规则

以下规则是紫府对公开讲解的工程化重述，只生成传统文化参详。`sourceEdition`、`sourceYear`、`sourceUrl` 必须存在；若输入只有 daily-core 当前的按日干静态宜忌，则不得标记为“蔡伯励/真步堂规则”。

1. **CBL-01 综合等级候选门槛**  
   `存在可追溯的真步堂年度记录 + 日等级 ∈ {上吉, 中吉, 平吉} → 加入候选日并显示原等级；等级低于平吉或缺失 → 不作蔡氏吉日推荐`  
   分数段可作为原版数据的校验字段，但不得自行用神煞重算；分数不是成功率。（参考蔡伯励，来源 A3：https://www.master-insight.com/article/1785）

2. **CBL-02 事项忌项否决**  
   `候选日 + targetActivity 命中该版通胜“忌” → 从该事项推荐集中移除，并返回 vetoReason；未命中“忌” → 仅保留候选资格，不输出“必宜/必成”`  
   这条规则适合扩展 daily-core 的事项级宜忌合并器，优先级高于单个建除、宿值或吉神加分。（参考蔡伯励，来源 A4：https://www.master-insight.com/article/1796）

3. **CBL-03 生肖相冲的个人化降级**  
   `候选日 + 用户自愿提供生肖 + 日支与生肖支相冲 → 标记“传统相冲”并移出个人推荐集；未提供生肖 → 跳过本规则，不以八字或其他资料代填`  
   该规则只复现公开讲解中的个人筛选步骤，不扩大为完整八字合婚或事件预测。（参考蔡伯励，来源 A3：https://www.master-insight.com/article/1785）

4. **CBL-04 多源冲突抑制**  
   `同一事项同时命中支持项与否决项 → 禁止净加总后输出“吉”；保留全部证据，按显式忌项否决，否则降为“冲突待复核”`  
   二十八宿仅作为低权重展示证据，建除也不得脱离原版综合结果单独翻转结论。（参考蔡伯励，来源 A4：https://www.master-insight.com/article/1796）

5. **CBL-05 跨地区择时输入门槛**  
   `请求精确到时辰 + 缺少事项发生地或 IANA 时区 → 不生成吉时；信息齐全 → 先换算当地民用时间和夏令时，再按已声明版本选择是否做经度修正；落在时辰边界缓冲区 → 输出“不确定，需复核”`  
   该规则只解决时间口径，不承诺天气或事件结果。（参考蔡伯励，来源 A4：https://www.master-insight.com/article/1796）

建议执行顺序：

```text
输入日期、地点、事项与可选生肖
  → 历法/时区数据校验
  → 装载指定年份、指定版本的通胜记录
  → 综合等级筛候选
  → 事项“忌”否决
  → 可选生肖相冲过滤
  → 建除解释 + 二十八宿低权重展示
  → 冲突抑制与边界不确定性
  → 传统文化参详 + 来源 + 版本
```

本执行顺序为前述规则的组合，不代表蔡真步堂未公开的内部编算公式；依据均见每条规则末尾 URL。

## 不可应用部分

1. **固定的建除全局吉凶表：** 公开讲解只明确举出除、执、定，并强调看编者综合等级；旧稿把建、除、定、成、开统称吉、把破、危、收统称凶，来源不足，不进入规则集。（来源 A4：https://www.master-insight.com/article/1796）
2. **固定的二十八宿吉凶分组：** 旧稿的“二十一吉、七凶”没有蔡氏来源，而且蔡伯励公开说明该字段在其通胜中偏记录用途；不得硬编码。（来源 A4：https://www.master-insight.com/article/1796）
3. **节气交接日或月建日的固定事项宜忌：** “交节日宜祭祀祈福、忌动土”“月建日宜开业签约、忌医疗搬迁”等旧稿规则均无来源，删除而不替换。（来源审查依据 A3：https://www.master-insight.com/article/1785；A4：https://www.master-insight.com/article/1796）
4. **把“不忌”改写成现实保证：** 未列忌只能作为该通胜版本的传统标记，不能覆盖法律许可、施工规范、天气预报、医疗意见或当事人现实条件。（来源 A4：https://www.master-insight.com/article/1796）
5. **从公开材料反推真步堂完整评分公式：** 目前只能确认分级结果和部分使用步骤，无法确认全部神煞、权重及冲突表；禁止以自造算法冒名。（来源 A3：https://www.master-insight.com/article/1785；A4：https://www.master-insight.com/article/1796）
6. **天气控制或天象因果承诺：** 演讲中的停雨、出太阳个案属于不可独立复核的事后叙述；蔡伯励本人也不愿保证所择时刻必有好天气，因此不得用于天气或工程安排。（来源 A4：https://www.master-insight.com/article/1796）
7. **堪舆形势自动判断：** 龙脉、水口、聚水、城市地运等依赖人工取象，公开材料没有可复现阈值；不得用卫星地图或图像模型自动输出风水吉凶。（来源 A5：https://www.master-insight.com/article/1804）
8. **“风水独立于八字”的归因：** 现有蔡氏材料不能支持这句话；本卡直接排除与择日引擎无关的风水和城市运势内容，不据此创建八字或风水规则。（来源 A5：https://www.master-insight.com/article/1804）
9. **城市、经济、疾病、灾祸等确定性预测：** 立春四柱、五行或城市大运的演讲个案不构成可验证预测模型，不进入产品。（来源 A5：https://www.master-insight.com/article/1804）
10. **以非遗或名人采用作为有效性证明：** 机构荣誉、出版传播和文化传承只能证明社会影响，不能证明吉凶推断正确。（来源 A1：https://www.cpr.cuhk.edu.hk/resources/press/pdf/5550489bd3634.pdf；来源 A2：https://www.iso.cuhk.edu.hk/chinese/publications/newsletter/article.aspx?articleid=61787）

## 研究可信度说明

- **A 级的含义：** 可较可靠地回答“谁说过什么、机构记录了什么、通胜公开展示哪些字段”。它不提升术数主张的科学可信度；演讲整理稿仍可能有口误、删节或编辑误差。（分层依据及样本来源：https://www.cpr.cuhk.edu.hk/resources/press/pdf/5550489bd3634.pdf；https://www.master-insight.com/article/1796）
- **B 级的含义：** 可交叉核验传承、出版和社会使用背景，但对算法细节只能作为旁证，不能覆盖一手材料。（样本来源：https://theinitium.com/20190202-culture-hongkong-traditional-calendar/）
- **C 级的含义：** 只用于发现关键词和版本线索；若结论只能找到 C 级材料，则不进入可应用规则。（样本来源：https://zh.wikipedia.org/wiki/%E5%BB%BA%E9%99%A4%E5%8D%81%E4%BA%8C%E7%A5%9E）
