# 邵伟华 · 方法论蒸馏

> 定位：本文只蒸馏可描述为判定流程的四柱方法，不认可命理具有科学预测效力，也不把个案“应验”当作因果证据。以下输出只适合做文化型、低风险的参详提示。

## 生平与体系概览

公开馆藏记录可确认，邵伟华在 20 世纪 90 年代出版了《四柱预测学》，内容属于四柱推命体系；另一部常被简称为“邵伟华四柱入门”的书，馆藏著录实际为陈园编著、邵伟华审订，不能混同为邵伟华独著。两书的目录与公开章节显示，其教学路线从阴阳五行、干支与十神起步，继而讨论日干旺衰、用神、神煞和岁运。与强调单一秘诀的宣传不同，可核对的文本更像一套以日主旺衰和五行平衡为中轴、再叠加刑冲合害与岁运的通俗化四柱教材。后世命理史类著作也把《四柱预测学》列入大陆现代命理著作序列，但这只能说明出版与传播史位置，不能证明预测结论为事实。

## 核心方法论

### 1. 日主强弱：月令优先，再做全局校正

**名称：** 得令—得地—得生—得助四项审查。

**逻辑链条：**

1. 先确定日干，并以月支所代表的时令状态作为第一层权重，而不是直接数五行个数。
2. 再看日干在其余地支是否有根（得地）、是否获印星生扶（得生）、是否获比劫同类协助（得助）。
3. 得令时，地、生、助再有有效支持，才提高“偏强”判断；失令时，也不能立即判弱，仍要检查多处有力生助以及三合、三会形成的生身或帮身力量。
4. 对临界盘，继续校正干支远近、旺地衰地、合去或合来、冲制以及会合后的五行方向。文本明确承认平衡盘不易定旺衰，因此工程上应输出置信度，而不是硬分强弱。

**适用场景：** 作为取用神、判断岁运喜忌之前的基础层；不适合脱离完整四柱单看一个天干或生肖。

**蒸馏结论：** 这套顺序是“月令给初始倾向，根、生、助给证据，克泄耗与合冲会局做反向校正”。它不是简单计数法，也不是绝对的月令一票否决制。

### 2. 格局与取用：以扶抑为主轴，通关和调候并参

**名称：** 失衡识别—候选用神—救应复核。

**逻辑链条：**

1. 先由日主强弱和局中哪类十神过多，识别主要失衡，不把“正官、七杀、财、印”等标签预设成天然吉凶。
2. 日主偏弱时倾向生扶：官杀偏多先考察印星能否泄杀生身，无印再看比劫；财星偏多先看比劫，无比劫再看印；食伤偏多先看印，无印再看比劫。
3. 日主偏强时倾向抑、耗、泄：印星偏多先看财能否制印耗身，再复核官杀或食伤会不会反而加重失衡；比劫偏多先看官杀制约，其次看食伤疏泄，再其次才看财耗。
4. 两股五行势力对峙而直接相克时，寻找能把克制关系改造成连续相生关系的“通关”五行。网络转录页有个别疑似错字，编码时应按五行关系计算桥接元素，不应照抄固定表。
5. 月令显示明显寒、暖、燥、湿偏态时，再加入调候维度：冬月关注火的暖燥作用，夏月关注水的寒润作用；春秋不强制补水火。调候须与扶抑一起复核，不能覆盖全局喜忌。
6. 最后检查候选用神在原局是否有力、受制、被合去或能得到救应；若多个原则冲突，应保留多个候选及冲突原因。

**适用场景：** 为命局生成“建议关注的平衡方向”，以及为大运流年提供喜忌参照。这里的“格局”更接近围绕旺衰与十神组合识别失衡，而不是只凭格名直接下结论。

**蒸馏结论：** 可编码的重点不是输出一个永远不变的“用神”，而是生成有理由、有优先级、可被合冲和调候修正的候选集合。

### 3. 神煞：保留但降级，必须服从原局

**名称：** 原局优先、神煞佐证。

**逻辑链条：**

1. 先完成日主旺衰、喜忌与干支刑冲合害分析，再查神煞，不能用一个神煞替代全局判断。
2. 邵氏审订的入门体系并非完全轻神煞：羊刃、天德、月德被赋予较高关注；华盖、天医、驿马、桃花等更多用于性格、兴趣或活动方式的辅助描述。
3. 同一神煞还要看所临干支是否有力、是否受刑冲克合、是否与命局喜忌方向一致；被制合或落在弱处时降低权重。
4. 工程实现中，神煞只应增加或降低已有主题的提示置信度，不应单独触发疾病、诉讼、伤亡、婚变等具体事件判断。

**适用场景：** 低权重文化解释、性格或行动主题补充；不适合高风险决策。

**蒸馏结论：** 其态度可概括为“用神煞，但不让神煞脱离旺衰喜忌独断”。这比“完全不用”更重，又比“一煞定事”更克制。

### 4. 大运流年：原局定坐标，大运定阶段，流年定触发

**名称：** 命—运—年三层联判。

**逻辑链条：**

1. 先以原局旺衰和候选用神建立喜忌坐标，再排大运、起运时间并把每步大运干支换算为十神。
2. 大运给出十年阶段倾向：运干参与天干与十神平衡，运支参与地支刑冲合会害，并对运干和用神产生增减作用。
3. 流年不脱离大运单断，而是在大运阶段范围内与原局、大运共同形成新的生克制化关系，用于标示可能被放大的年份主题。
4. 最终判断重点不是“逢冲必凶、逢合必吉”，而是冲合究竟作用于候选用神、喜神还是忌神，以及原局是否已有制化或救应。
5. 同一流年在顺势大运与逆势大运中的提示强度应不同；大运和流年方向相反时，输出“混合/受限”而不是让流年覆盖十年背景。

**适用场景：** 生成阶段性趋势和年度关注主题，不适合断言某年必然发生某件具体事件。

**蒸馏结论：** 可编码为 `原局喜忌 → 大运阶段基线 → 流年增减/触发 → 合冲制化复核 → 概率化提示` 的链条。

### 5. 推荐的引擎执行顺序

```text
输入校验
  → 排四柱、藏干、十神
  → 月令初判
  → 得地/得生/得助与克泄耗校正
  → 合冲会局、远近和旺衰复核
  → 输出日主倾向 + 置信度
  → 生成扶抑/通关/调候候选
  → 检查用神受制与救应
  → 大运阶段基线
  → 流年触发修正
  → 神煞低权重佐证
  → 参详提示 + 反证 + 不确定性
```

## 可应用规则

以下规则只产出参详提示；`有效`表示未被明显合去、冲制且自身不处于显著弱势，实际权重应由统一五行强度模型计算。

1. **SWH-01 月令优先的偏强提示**  
   `日主得令 + 得地/得生/得助至少一项有效 → 提示“日主较有偏强倾向；请继续核对克泄耗、合化与支持力量，当前并非最终强弱结论”（参考邵伟华审订体系，来源 https://www.sizhuyucexue.com/thread-65-1-1.html）`

2. **SWH-02 失令后的反转审查**  
   `日主失令 + 得地/得生/得助中至少两类有力，或会合成生身/帮身之势 → 提示“虽失月令，仍有由弱转中和或偏强的可能；建议降低强弱结论置信度并做全局复核”（参考邵伟华审订体系，来源 https://www.sizhuyucexue.com/thread-65-1-1.html）`

3. **SWH-03 身弱官杀偏多的候选用神**  
   `日主偏弱 + 官杀力量明显高于其他克泄耗项 → 提示“可优先考察印星能否泄官杀并生身；印不可用时，再考察比劫帮身。两者都须检查受制与副作用”（参考邵伟华审订体系，来源 https://www.sizhuyucexue.com/thread-74-1-1.html）`

4. **SWH-04 身弱财多或食伤多的分支**  
   `日主偏弱 + 财星偏多 → 提示“先考察比劫、再考察印星的平衡作用”；日主偏弱 + 食伤偏多 → 提示“先考察印星、再考察比劫的平衡作用”（参考邵伟华审订体系，来源 https://www.sizhuyucexue.com/thread-73-1-1.html）`

5. **SWH-05 身强的抑耗泄分支**  
   `日主偏强 + 印星偏多 → 提示“优先考察财星制印耗身，并复核官杀、食伤是否加重冲突”；日主偏强 + 比劫偏多 → 提示“依次考察官杀制、食伤泄、财星耗的可用性”（参考邵伟华审订体系，来源 https://www.sizhuyucexue.com/thread-73-1-1.html）`

6. **SWH-06 通关与调候候选**  
   `两种有力五行直接对峙 + 存在可把双方连接成连续相生的中介五行 → 提示“中介五行可列为通关候选”；冬月且整体寒湿明显 → 追加“关注火的暖燥维度”；夏月且整体燥热明显 → 追加“关注水的寒润维度”（参考邵伟华审订体系，来源 https://www.sizhuyucexue.com/thread-73-1-1.html）`

7. **SWH-07 神煞降权规则**  
   `神煞命中 + 未得到原局喜忌、旺衰及刑冲合害同向支持 → 不生成具体事件结论；神煞命中 + 多项原局证据同向 → 仅生成低权重的性格/行动主题提示，并展示“传统神煞参详”标签（参考邵伟华审订体系，来源 https://www.sizhuyucexue.com/thread-1336-1-1.html）`

8. **SWH-08 岁运两层修正**  
   `大运支持候选用神 + 流年继续生助或解除其受制 → 提示“阶段背景与年度信号同向，可提高该主题关注度”；大运与流年方向相反 → 提示“年度信号受十年阶段约束，呈混合倾向，不宜单年定论”（参考邵伟华审订体系，来源 https://www.sizhuyucexue.com/thread-81-1-1.html）`

本节结论来源：每条规则末尾已逐条标注 URL；规则为紫府基于来源逻辑的工程化重述，不是原书断语。

## 不可应用部分

1. **传奇生平与“神准预测”故事：** 网络简介常出现名人事件、血缘传承、荣誉称号等说法，缺乏足够独立材料交叉核验，不进入规则集。
2. **把命理包装成自然科学、人体信息科学或遗传规律：** 这是作者及传播材料的主张，不是经现代科学验证的模型；只能作为思想史背景。
3. **死亡、疾病、牢狱、灾伤等确定性断语：** 即使转录命例声称“应验”，也可能存在选择偏差、事后解释和资料不可复核问题，不得进入产品提示。
4. **一神煞一事件：** 羊刃、桃花、驿马、华盖等不得直接映射暴力、婚变、迁移、宗教倾向或职业。
5. **通过姓名、方位、颜色、物件等“补用神”即可改运的因果承诺：** 缺少可验证机制，不进入规则集。
6. **性别二元排运规则的无条件应用：** 传统排运法含基于男女的顺逆设定；现代产品若使用，必须说明它是传统算法参数，并提供算法版本，不把性别角色推演为现实结论。
7. **在线转录中的固定口诀直接硬编码：** 网络文本不是校勘本，存在错字、脱文和作者归属混称；应把它当研究线索，以五行关系计算与正式版本复核为准。
