# 八大师方法论蒸馏工程（2026-08-16 启动）

## 目标

学习八位玄学名家（陈朗/曾仕强/蔡伯励/邵伟华/梁湘润/王其亨/白龙王/李居明）
的公开分析与教学，蒸馏其**方法论逻辑**，转化为紫府引擎可应用的推演规则。

## 红线（比项目铁律更严）

1. **不引原文**：大师著作是现代出版物（有版权），蒸馏用紫府自己的语言重述，
   禁止大段抄录原文
2. **来源可溯**：每条蒸馏结论标注参考 URL（网络公开资料）
3. **区分事实与传说**：可验证的方法论 vs 坊间传说/营销包装必须分开标注
4. **无确定性断言**：蒸馏出的规则用于"参详维度"（提示用户参考），
   不输出生死病灾断言
5. **白龙王特殊处理**：无著作，仅民间口碑——只做"文化现象"条目，不进规则集

## 蒸馏文档模板

```markdown
# <大师名> · 方法论蒸馏

## 生平与体系概览（3-5 句，来源 URL）
## 核心方法论（每个方法：名称/逻辑链条/适用场景）
## 可应用规则（Hermes 提炼：可编码的判定逻辑，格式：
   `条件A + 条件B → 提示C（参考大师名，来源URL）`）
## 不可应用部分（传说/营销/需人工判断的，明确排除）
## 来源清单（URL 列表）
```
