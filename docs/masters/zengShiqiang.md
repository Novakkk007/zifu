# 曾仕强 · 方法论蒸馏

## 生平与体系概览（3-5 句，来源 URL）
曾仕强教授（1935-2018）是台湾著名国学大师、易经研究专家，曾任台湾交通大学教授。他以通俗化、生活化的讲解方式将《易经》智慧转化为现代人可理解的思维工具，强调"易为君子谋"的实用哲学。其教学体系注重将卦象、爻辞与日常生活情境对应，形成情境判断框架。（参考：https://baike.baidu.com/item/曾仕强）

## 核心方法论（每个方法：名称/逻辑链条/适用场景）
### 1. 情境三要素分析法
逻辑链条：任何决策需同时考虑「时间」（时位）、「空间」（位置）、「人事」（关系）三个维度；《易经》六十四卦即不同情境组合的映射。
适用场景：职场决策、人际关系处理、重大人生选择。

### 2. 阴阳动态平衡观
逻辑链条：阴阳不是静态对立，而是动态转化关系；吉凶判断需看阴阳是否处于恰当的转化阶段，而非简单好坏二分。
适用场景：危机应对、变革管理、健康养生。

### 3. 卦象情境映射法
逻辑链条：将具体问题映射到相应卦象（如"困卦"对应资源受限情境，"泰卦"对应通达顺畅情境），通过卦辞爻辞获得情境性启示而非绝对答案。
适用场景：项目管理、团队建设、个人发展路径规划。

## 可应用规则（Hermes 提炼：可编码的判定逻辑，格式：`条件A + 条件B → 提示C（参考大师名，来源URL）`）
`情境中存在明显的时间节点约束 + 空间位置变化需求 → 提示：参考"时位"概念，评估当前时机与位置匹配度（参考曾仕强，https://baike.baidu.com/item/曾仕强）`
`关系网络中出现明显对立力量 + 当前状态趋于稳定 → 提示：警惕阴阳转化临界点，准备应对动态变化（参考曾仕强，https://baike.baidu.com/item/曾仕强）`

## 不可应用部分（传说/营销/需人工判断的，明确排除）
- 八字命理推算（曾仕强本人未系统建立八字体系，此属其他大师领域）
- 风水布局具体操作（非其教学重点，属蔡伯励等大师专长）
- 确定性命运断言（违背其"易为君子谋"核心理念）
