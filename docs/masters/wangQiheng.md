# 王其亨 · 方法论蒸馏

> 定位：本文蒸馏的是建筑史、规划史与文献学研究流程，不把传统风水当作能够预测个人吉凶的科学模型。可应用内容只用于资料核验、历史空间解释与低风险的规划检查。

## 生平与体系概览

公开人物卡将王其亨记为天津大学建筑学院教授，研究领域包括古建筑测绘、样式雷图档与中国古代建筑图学；由于该人物卡属于网络百科，本项身份信息按中等可信处理，不据此扩写荣誉与完整履历。（来源：https://baike.baidu.com/api/openapi/BaikeLemmaCardApi?scope=103&format=json&appid=379020&bk_key=%E7%8E%8B%E5%85%B6%E4%BA%A8&bk_length=1200）

可访问书目记录显示，他参与的研究覆盖传统生态智慧、古代城市规划与风水理论、中国营造学社的文献学方法以及传统建筑分类。这些材料共同呈现的不是一套吉凶断语，而是一条“历史文献梳理—实物或图档互证—环境与空间因素解释—结论保留语境”的建筑史研究路径。（来源：https://api.openalex.org/works/W1502611769；https://api.openalex.org/works/W593076228；https://api.openalex.org/works/W656352256；https://api.openalex.org/works/W2252291873）

## 核心方法论

### 1. 把风水材料还原为历史规划问题

**名称：** 典籍—规划实践—环境指标解释。

**逻辑链条：** 先确定典籍与历史规划活动的关系，再从材料中分离资源考察、环境容量、城市生态结构与选址取中等可讨论因素，最后说明这些因素所处的时代背景；不能从古代术语直接跳到现代吉凶结论。（来源：https://api.openalex.org/works/W593076228）

**适用场景：** 古代城市规划史、传统聚落选址史与风水观念史研究；不适合个人命运预测。（来源：https://api.openalex.org/works/W593076228）

### 2. 文献与实物相互校验

**名称：** 双重证据核验。

**逻辑链条：** 研究从收集、整理营造文献开始，解释深入后再把典籍记载与建筑实物、测绘材料或图档相互核对；两类证据一致时提高结论可信度，不一致时保留问题并回查版本、年代和对象。（来源：https://api.openalex.org/works/W656352256）

**适用场景：** 建筑史、营造制度史、古建筑测绘与档案研究。（来源：https://api.openalex.org/works/W656352256）

### 3. 在比较中识别生态价值层与事实层

**名称：** 传统生态观的历史比较。

**逻辑链条：** 先分别梳理中西生态思想的来源、演进与主要观点，再比较其中的生态伦理取向和现实意义；价值启发与可测量的工程性能必须分开，不能因理念相近就宣称技术效果已经得到验证。（来源：https://api.openalex.org/works/W1502611769）

**适用场景：** 建筑文化研究、生态思想史与设计价值讨论；具体节能、通风、采光效果仍须另做工程测算。（来源：https://api.openalex.org/works/W1502611769）

### 4. 以语境处理传统建筑分类

**名称：** 语境化分类。

**逻辑链条：** 面对传统建筑名称宽泛、边界模糊的情况，先记录名称出现的时代、用途和上下文，再提出候选分类；不强迫历史称名完全服从现代形式逻辑，也不把一个名称永久绑定为唯一类型。（来源：https://api.openalex.org/works/W2252291873）

**适用场景：** 历史建筑资料标注、知识库归类与跨文献名称对齐。（来源：https://api.openalex.org/works/W2252291873）

## 可应用规则

以下规则仅生成研究提示或规划检查项，不生成方位吉凶、人生事件与工程安全结论。

1. **历史规划因素拆分规则**
   `材料明确涉及古代选址或城市规划 + 能识别资源条件、环境容量、生态结构或空间取中因素 → 分项记录可观察因素，并标注历史语境；不得输出“吉地”或“凶地”`（来源：https://api.openalex.org/works/W593076228）

2. **双重证据增信规则**
   `营造文献记载 + 实物、测绘或图档证据同向 → 提高该建筑史结论的资料可信度；两类证据冲突 → 标记“待核版本、年代与对象”，不强行合并`（来源：https://api.openalex.org/works/W656352256）

3. **生态主张分层规则**
   `传统生态观念 + 当代价值目标相近 → 只生成“可作价值参照”的提示；缺少性能测量或工程验证 → 不生成节能、舒适或安全效果结论`（来源：https://api.openalex.org/works/W1502611769）

4. **传统称名保留语境规则**
   `同一传统建筑名称在不同材料中的定义不一致 + 差异可由时代、用途或上下文解释 → 保留多个候选分类并记录各自语境；证据不足 → 降低分类置信度`（来源：https://api.openalex.org/works/W2252291873）

本节规则是对学术研究流程的工程化重述，只能作为资料治理与研究辅助逻辑；是否进入任何产品规则集，仍须另行审查。

## 不可应用部分

1. **方位吉凶与个人命运映射：** 论文讨论的是古代城市规划与风水观念的历史关系，不能据此断言某方位必然带来财富、疾病或灾祸。（来源：https://api.openalex.org/works/W593076228）
2. **古代经验直接替代现代工程：** 传统生态观具有思想史与伦理讨论价值，但不能替代结构、消防、能耗、采光、通风和环境影响评估。（来源：https://api.openalex.org/works/W1502611769）
3. **只凭文献或术语下定论：** 缺少实物、测绘、图档或版本核验时，不把单一记载当作已证实的建筑史事实。（来源：https://api.openalex.org/works/W656352256）
4. **把模糊称名硬编码为唯一类别：** 传统建筑命名受实用思维与语境影响，不能脱离上下文建立永久的一对一映射。（来源：https://api.openalex.org/works/W2252291873）
5. **把网络人物卡当完整学术档案：** 人物卡仅用于基本身份线索，荣誉、项目贡献与著作归属仍应回到机构档案和正式出版记录复核。（来源：https://baike.baidu.com/api/openapi/BaikeLemmaCardApi?scope=103&format=json&appid=379020&bk_key=%E7%8E%8B%E5%85%B6%E4%BA%A8&bk_length=1200）
