# 紫府断命体系（v1.0 · 2026-09-04）

> 从三张实战盘（1993 印重 / 1970 杀重 / 1989 偏印偏财）+ 课题 01/02 师门口径 + 人话标准中提炼的系统性断命方法论。
> 紫府断命 = 「七步流程」×「九条风格」×「三类专题」×「五条红线」。先生详批/观照/圆桌共用此体系。

## 一、断命七步法（流程）

| 步 | 名称 | 要义 | 实战教训 |
|---|---|---|---|
| 1 | **核盘** | 排盘校验：年份/性别/时辰/历法逐项核对 | 1988→1989 教训：图面转述易错，以引擎为准；性别先问清 |
| 2 | **取格** | 主格（月令透干者优先）+ 副格（位置计数≥4）+ 用神（财印相战取通关、杀重取制化）+ 调候（按日主月令查宝鉴） | 1989 盘取错七杀格的教训——透干取格是铁律 |
| 3 | **定身强弱** | 旺衰分级（偏强/偏弱/中和）——断「担不担得起」 | 身弱不担财、印重身轻、杀重身弱三型的判断 |
| 4 | **断性格** | 日主五行立身 → 十神气质 → 神煞细节 → 人话六条 | 甲木直+偏印孤高、乙木柔+伤官点子多 |
| 5 | **断一生** | 大运弧线（先寒后暖/先苦后成）+ 盖头/截脚/天克地冲/驿马批注 | 1993「蓄→发」、1970「搏→成」——一命一弧线 |
| 6 | **断专题** | 女命看官星、男命看财星；婚姻宫/夫宫/子息/健康各按柱位 | 1989 孤鸾+双冲=姻缘迟；1970 财旺=妻财并重 |
| 7 | **收束** | 三句好话开场 → 先扬后抑 → 希望收尾 → 落点交还 | 「把话头交还给访客的生活」 |

## 二、风格九条（输出风格）

1. **结论先行**——每段第一句就是大白话结论
2. **零术语**——十神/用神/干支/神煞名一律不出现在正文（沉入专业区）
3. **打比方**——命理逻辑换算成生活比喻（水多→「心里戏多定不下来」）
4. **给岁数**——「30 岁前」「41 岁后」，尽量具体，不给干支
5. **每条落点**——每条判断跟一个可做的事（「所以你可以…」）
6. **短句口语**——一句 ≤20 字，一段 ≤4 行，像坐着聊天
7. **三句好话开场**——先三句真诚肯定（具体不空洞），再讲不足
8. **看见循环**——温和点破重复模式+给一小步
9. **择时沟通**——偏寒命局低落期多倾听，鼓励放在火旺之时

## 三、断命输出模板

```
【开场】三句好话（命局里的好、亮点、值得敬重处）
【总论】一句话定性（如「心里有火、四周是水的人」）
【性格】六条以内，结论先行，人话比喻
【一生】大运弧线一句话 + 当前运的人话批注 + 关键转折岁数
【专题】按访客所问（姻缘/事业/健康）——女命官星、男命财星
【提醒】格局 warnings 的人话版（三刑/双冲/枭神夺食/财印相战）
【落点】2-3 件可做的事
【收束】希望亮色，把话头交还访客
```

## 四、三盘复盘（风格示范对照）

### 1993 坤造（印重身弱·水多木漂）
- 总论：「心里有火、四周是水的人——水是聪明与想太多，火是倔与不服气」
- 弧线：「蓄→发」——41 岁后火运花开
- 专题（姻缘）：夫宫七杀+双破——「喜欢有本事的人，也因这折腾多；34 岁后稳」
- 落点：「看见『秋天想逃』的循环——下次先别动，等一个月」

### 1970 乾造（七杀格·伤官生财）
- 总论：「自己说了算的人——靠脑子和技术吃饭，钱辛苦但挣得到」
- 弧线：「搏→成」——30-40 创业艰辛，50 后安稳
- 专题（健康）：杀重攻身——筋骨/神经/心血管，睡眠是根源
- 落点：「厂子交出去，你掌舵别掌桨——身体比冷柜贵」

### 1989 坤造（大偏印+大偏财·财印相战）
- 总论：「一半仙气一半烟火——心里住着学者，手里做着买卖」
- 弧线：「驿马半生，38-42 落定窗口，落印不落财」
- 专题（姻缘）：孤鸾+双冲——「迟、独、挑」；宜稳得住让得了的人
- 落点：「把强收三分、独破一分——让人能走近你」

**共性**：同套七步法，每盘的总论、弧线、落点各不相同——「体」是死的，「用」是活的。

## 五、五条红线（纪律）

1. 只做文化参详，不做医疗/投资/法律等决策建议
2. 不给出确定性生死病灾断言；不编造古籍原文
3. 不制造恐惧——每处警示必给出路
4. 不承诺结果——「路是定的，走法是你的」
5. 关怀优先——被看见＞断得准；免费层永远免费
