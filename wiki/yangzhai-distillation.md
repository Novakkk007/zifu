# 阳宅蒸馏：九条可展示规则

> 藏经阁内容 · 公版典籍文化整理 · 仅作空间维护提示，不作吉凶断语

## 规则索引

| ID | 标题 | 核心观察 |
|---|---|---|
| YZ-01 | 空间使用 | 住宅面积与常住人数是否失衡 |
| YZ-02 | 入口比例 | 入口尺度与内部空间比例是否协调 |
| YZ-03 | 围护完整 | 院墙/门窗/屋面/外墙是否破损 |
| YZ-04 | 井灶适位 | 饮用水/排污设施与厨房位置是否合理 |
| YZ-05 | 门主关系 | 入户门视线是否直达主要卧室/起居区 |
| YZ-06 | 门灶关系 | 入户/通行路线是否穿越烹饪操作区 |
| YZ-07 | 宅向复核 | 宅向信息是否完整可靠 |
| YZ-08 | 宅命请求 | 出生年/性别匹配请求 |
| YZ-09 | 多体系冲突 | 不同风水体系得出的冲突标签 |

## 详细规则

### YZ-01 空间使用

**条件：** 住宅面积明显大于实际需求 + 常住人数少/大量长期空置

**提示：** → “可检查空置房间的渗漏、霉变、通风、能耗与维护成本；这对应古籍‘宅大人少’的空间观察，不代表贫富结果。”

### YZ-02 入口比例

**条件：** 入口尺度/开口明显大 + 内部空间小或入口直曝主要起居区

**提示：** → “可复核保温、噪声、私密、门扇碰撞与疏散净宽；不要仅凭‘门大’判断好坏。”

### YZ-03 围护完整

**条件：** 院墙/门窗/屋面/外墙出现破损、松动或渗漏

**提示：** → “优先安排结构与围护巡检，处理坠落、进水、虫害和安防风险；这是维护建议，不是灾祸预测。”

### YZ-04 井灶适位

**条件：** 饮用水/排污设施与厨房相邻不当，或燃气、排烟、防火条件不明

**提示：** → “请按当地给排水、燃气和消防规范复核，必要时请持证专业人员检测；古代方位法不能替代检测。”

### YZ-05 门主关系

**条件：** 入户门视线直达主要卧室/起居私密区

**提示：** → “可用玄关、错位收纳或可控遮挡改善私密与声光干扰，同时保持疏散通道畅通。”

### YZ-06 门灶关系

**条件：** 主要入户/通行路线穿越烹饪操作区，或强穿堂风掠过灶具

**提示：** → “复核碰撞、烫伤、火焰稳定和排烟风险；调整方案必须先满足消防、燃气与通行规范。”

### YZ-07 宅向复核

**条件：** 用户提供宅向 + 门位 + 主位，但没有真北、测量误差、户型或现场数据

**提示：** → “信息不足，暂不判方位；请补充可靠测量和空间资料。即使资料齐全，也只给文化标签与环境检查项。”

### YZ-08 宅命请求

**条件：** 输入出生年/性别，要求匹配住宅或断吉凶

**提示：** → “宅命相配属于传统术数分类，不能据此预测事件；可改按居住者的行动、作息、采光、安静和无障碍需求评估。”

### YZ-09 多体系冲突

**条件：** 《宅经》二十四路 + 后世八宅/门主灶表得出冲突标签

**提示：** → “标注来源时代和体系不同，不强行合并、不择凶词放大；转回可测的采光、风、噪声、消防和卫生指标。”
